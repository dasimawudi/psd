# 双维度评估脚本使用说明

本文说明如何复现 `node/doc/耳片与圆盘中心双维度评估汇总_20260613.md` 中的主要指标和图表。

## 1. 环境

在仓库根目录运行，建议使用：

```bash
export PYTHONPATH=node
PY=/data1/libo/miniconda3/envs/yolo/bin/python
```

## 2. 关键模型

圆盘中心：

```text
node/outputs/node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m/best.pt
```

耳片 best：

```text
node/outputs/node_mlp_v5_exp_region_distance_within25_50ep/best.pt
```

## 3. case-node-f 逐频应力维度

统计单位是 `(case, node, frequency)`，目标是 `MISES_psd_density`。

### 3.1 标准 test 指标

```bash
$PY node/evaluate_node_mlp.py \
  --checkpoint <best.pt> \
  --split test \
  --output-dir <model_output>/eval_test \
  --device cuda \
  --num-workers 8 \
  --sample-batch-size 64 \
  --point-batch-size 4194304 \
  --no-curve-diagnostics
```

输出：

```text
<model_output>/eval_test/test_metrics.json
<model_output>/eval_test/test_diagnostics.csv
```

### 3.2 per-frame top 百分比指标

脚本：

```text
node/evaluate_case_node_f_top_percent.py
```

定义：每个 case-frequency frame 内，按真实 `MISES_psd_density` 排序，取 top1% / top5% / top10% / top15% / top25%。

圆盘中心示例：

```bash
$PY node/evaluate_case_node_f_top_percent.py \
  --checkpoint node/outputs/node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m/best.pt \
  --split test \
  --output-dir node/outputs/node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m/eval_test_top_percent_custom \
  --device cuda \
  --num-workers 8 \
  --sample-batch-size 64 \
  --point-batch-size 4194304
```

耳片示例：

```bash
$PY node/evaluate_case_node_f_top_percent.py \
  --checkpoint node/outputs/node_mlp_v5_exp_region_distance_within25_50ep/best.pt \
  --split test \
  --output-dir node/outputs/node_mlp_v5_exp_region_distance_within25_50ep/eval_test_top_percent_custom \
  --device cuda \
  --num-workers 8 \
  --sample-batch-size 64 \
  --point-batch-size 4194304
```

输出：

```text
case_node_f_top_percent_metrics.json
case_node_f_top_percent_metrics.csv
```


## 4. case-node 最终 RMises 维度

统计单位是 `(case, node)`，先按频率积分：

```text
RMises = sqrt(∫ MISES_psd_density df)
```

### 4.1 生成 per-node RMises

脚本：

```text
node/summarize_final_rmises_topk.py
```

必须加 `--write-per-node`，后续百分比 top-k 和分位图都依赖 per-node 明细。

```bash
$PY node/summarize_final_rmises_topk.py \
  --checkpoint <best.pt> \
  --split test \
  --output-dir <model_output>/final_rmises_with_per_node_test \
  --device cuda \
  --num-workers 8 \
  --sample-batch-size 64 \
  --point-batch-size 4194304 \
  --write-per-node
```

输出：

```text
summary.json
case_summary.csv
top_band_summary_by_case.csv
top_nodes_by_case.csv
cases/*_final_rmises_per_node.csv
```

### 4.2 final RMises top 百分比指标

脚本：

```text
node/evaluate_final_rmises_top_percent.py
```

定义：每个 case 内，按真实最终 RMises 排序，取 top1% / top5% / top10% / top15% / top25%。

```bash
$PY node/evaluate_final_rmises_top_percent.py \
  --input-dir <model_output>/final_rmises_with_per_node_test \
  --output-dir <model_output>/final_rmises_with_per_node_test/rmises_by_case_and_quantile_plots
```

输出：

```text
final_rmises_top_percent_metrics.json
final_rmises_top_percent_metrics.csv
```

### 4.3 by-case 和 RMises 分位图

当前图表由 `final_rmises_with_per_node_test/cases/*_final_rmises_per_node.csv` 汇总生成，输出目录统一为：

## 5. 训练集热点/背景数量统计

脚本：

```text
node/count_train_target_hotspot_background.py
```

定义：每个训练集 case-frequency frame 内，按真实 `MISES_psd_density` 排序，topX% 为热点，剩余为背景。

圆盘中心示例：

```bash
$PY node/count_train_target_hotspot_background.py \
  --checkpoint node/outputs/node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m/best.pt \
  --name disk_center_continue70_4m \
  --num-workers 8 \
  --sample-batch-size 64
```

耳片示例：

```bash
$PY node/count_train_target_hotspot_background.py \
  --checkpoint node/outputs/node_mlp_v5_exp_region_distance_within25_50ep/best.pt \
  --name earpiece_best \
  --num-workers 8 \
  --sample-batch-size 64
```

输出：

```text
node/outputs/training_region_counts/<name>_train_target_hotspot_background_summary.json
node/outputs/training_region_counts/<name>_train_target_hotspot_background_summary.csv
```

## 6. 复现当前汇总文档的推荐顺序

1. `evaluate_node_mlp.py`：标准 test 指标。
2. `evaluate_case_node_f_top_percent.py`：逐频 top 百分比指标。
3. `summarize_final_rmises_topk.py --write-per-node`：最终 RMises 明细。
4. `evaluate_final_rmises_top_percent.py`：最终 RMises top 百分比指标。
5. 分位/绘图脚本：生成 p1 分位图和 by-case 图。
6. `count_train_target_hotspot_background.py`：训练集热点/背景样本数量。

## 7. 口径提醒

- `top1%` 等百分比口径不是固定节点数 topK。
- 逐频维度的 top 百分比是在每个 case-frequency frame 内排序。
- RMises 维度的 top 百分比是在每个 case 内排序。
- target 分位图的 p99-p100 是全局 target 分位，与 per-frame top1% 不是同一批点。
