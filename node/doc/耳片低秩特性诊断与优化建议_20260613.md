# 耳片低秩特性诊断与优化建议

日期：2026-06-13

## 背景

圆盘中心模型引入 `low_rank_curve_head` 后，overall within25 可以提升到约 0.81；耳片模型引入同类结构后，当前 rank8 实验 overall within25 约 0.59-0.60。为了判断这是训练未收敛、实现问题，还是耳片数据本身不够低秩，需要直接对目标数据做低秩谱分析。

本文结论基于两类证据：

- 原始目标场的 SVD 低秩诊断。
- 当前耳片 low-rank 训练结果与原 v6 allpoints 结果对比。

## 诊断方法

使用现有脚本：

```bash
/data1/libo/miniconda3/envs/yolo/bin/python node/center_curve_low_rank_diagnostics.py \
  --config node/configs/node_mlp_v6_earpiece_allpoints.yaml \
  --split val \
  --output-dir node/outputs/node_mlp_v6_earpiece_low_rank_diagnostics_val16_512nodes \
  --num-cases 16 \
  --max-frames-per-case 512 \
  --max-nodes 512 \
  --top-fraction 0.05
```

诊断逻辑：

1. 对每个 case，收集该 case 下多个频率点的目标应力场。
2. 构造矩阵 `M = nodes x frequencies`。
3. 对目标值做 `log1p` 后，做行/列中心化。
4. 对中心化矩阵做 SVD。
5. 统计 rank1/rank2/rank3/rank5/rank10 的能量解释率。

输出文件：

- `node/outputs/node_mlp_v6_earpiece_low_rank_diagnostics_val16_512nodes/val_low_rank_summary.csv`
- `node/outputs/node_mlp_v6_earpiece_low_rank_diagnostics_val16_512nodes/val_low_rank_summary.json`
- 对照圆盘诊断：`node/outputs/node_mlp_v6_disk_center_low_rank_diagnostics/test_low_rank_summary.csv`

## 低秩性对比

对齐到同样 `max_nodes=512` 后：

| 区域 | cases | rank1 | rank2 | rank3 | rank5 | rank10 | mean pairwise corr |
|---|---:|---:|---:|---:|---:|---:|---:|
| 圆盘中心 | 32 | 0.8876 | 0.9727 | 0.9951 | 0.9995 | 0.99999 | 0.9995 |
| 耳片 | 16 | 0.6550 | 0.8246 | 0.9105 | 0.9701 | 0.9945 | 0.9570 |

结论：

- 圆盘中心是强低秩结构。rank3 已经解释约 99.5% 的目标场变化，rank5 接近完全解释。
- 耳片有低秩性，但明显弱得多。rank3 只能解释约 91.1%，rank5 约 97.0%，rank10 才接近 99.5%。
- 因此，耳片不是不适合低秩，而是不适合像圆盘中心一样用很低 rank 的结构主导全部输出。

这些 case 说明耳片存在更复杂的局部频响形态，可能包括：

- 多热点随频率切换。
- 孔边、圆角、根部、桥区之间的局部响应形态不一致。
- 局部高梯度区域与背景区域的频响不共享同一组低秩基。

## 当前训练结果对照

当前耳片 rank8 low-rank 实验：

| 模型 | epoch | log MAE | overall within25 | top1 within25 | top5 within25 | peak rel |
|---|---:|---:|---:|---:|---:|---:|
| 原 v6 allpoints | 24 | 0.2838 | 0.5951 | 0.8723 | 0.7751 | 0.1681 |
| rank8 low-rank | 15 | 0.2849 | 0.5920 | 0.8626 | 0.7601 | 0.1314 |
| rank5 low-rank | 14 | 0.2860 | 0.5901 | 0.8536 | 0.7536 | 0.1291 |

现象：

- rank8 已经非常接近原 v6 allpoints。
- peak relative error 明显优于原模型，说明 low-rank 对峰值幅值和整体频响趋势有帮助。
- overall/top1/top5 仍略低于原 v6，说明 low-rank 作为主输出时仍会压缩一部分点级局部自由度。

## 为什么圆盘 overall 高而耳片低

圆盘中心的 overall within25 高，主要因为该区域非热点/背景点也高度共享相似频响曲线。其曲线相关性接近 1，低 rank 基本能表达大多数节点。

耳片则不同：

- top1/top5 区域目前并不差，甚至 peak rel 优于圆盘和原 v6。
- 差距主要来自非 top5 和中低应力区域。
- 耳片几何复杂，应力集中区和背景过渡区的局部响应不完全共享同一频响基。

因此，不能只看 overall within25 判断 low-rank 是否有效。对耳片应同时看：

- peak rel
- top1 within25
- top5 within25
- 分 rank band 的 within25
- 非 top5/background within25

## 结构判断

当前 low-rank 前向结构是：

```python
regression = low_rank + residual_weight * pointwise
```

rank8 配置中 `residual_weight=0.20`。这意味着原 pointwise 模型只以 20% 权重参与最终输出，low-rank 分支承担主预测。

对圆盘中心，这种设计合理，因为目标本身极强低秩。

对耳片，这种设计偏强约束。耳片需要：

- low-rank 捕获全局频响主趋势。
- pointwise 保留局部几何、孔边、圆角、根部、桥区的细节自由度。

## 建议实验优先级

### 1. 改 fusion：以 pointwise 为主，low-rank 做残差校正

优先级最高。

建议新增模式：

```python
regression = pointwise + alpha * low_rank_delta
```

或者：

```python
regression = pointwise + alpha * (low_rank - detached_or_learned_baseline)
```

目的：

- 保留原 v6 allpoints 的点级精度。
- 让 low-rank 只修正频响趋势、峰值幅值和跨频率一致性。
- 避免 low-rank 主导时压掉耳片局部细节。

### 2. 试 rank12/rank16，但不应作为第一优先级

SVD 显示耳片 rank10 才接近 99.5% 解释率，因此 rank12/rank16 有理论依据。

建议配置：

- rank12 / residual 0.25
- rank16 / residual 0.25

但单纯提高 rank 不能解决“low-rank 主导输出”的结构问题，所以优先级低于 fusion 改造。

### 3. 分区域 low-rank/gated low-rank

耳片可以按局部结构分组：

- root
- bridge
- hole
- outer/local body

可选做法：

- 每个区域独立 mixing head。
- 每个区域独立 curve basis。
- 用 region mask 或 gate 对不同 basis 加权。

目的：避免用一组统一低秩基同时表达孔边、圆角、根部和背景区域。

### 4. 加强非 top5/background 校准

当前 top1/top5 已经较强，overall 卡住说明背景和中低应力区需要额外约束。

建议：

- 增加 rank band balanced loss。
- 对 `50-100%` 或非 top5 区域提高 within25 相关权重。
- 控制低应力点过预测和欠预测的偏置。

### 5. 做 worst-case 曲线可视化

优先分析：

- `case522_mises_full_export`
- `case996_mises_full_export`
- `case830_mises_full_export`

需要看：

- 真实热点是否随频率迁移。
- 是否存在多峰频响。
- low-rank 预测是否把多个局部峰抹平。
- 背景区域是系统性过预测还是欠预测。

## 最终判断

耳片数据具备一定低秩特性，但明显弱于圆盘中心。当前 rank8 low-rank head 的收益主要体现在峰值幅值和频响趋势上，但作为主输出会牺牲一部分耳片局部点级自由度。

后续最合理方向不是放弃 low-rank，而是调整其角色：

> 对耳片，应该采用“pointwise 主预测 + low-rank 结构化残差/校准”的混合模型，而不是“low-rank 主预测 + 少量 pointwise residual”。
