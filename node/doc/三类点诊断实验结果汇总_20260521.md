# 全零件三类点诊断实验结果汇总

更新日期：2026-05-21  
分支：`dali/within25-diagnostics-cuda2`  
目的：用三个 specialist 诊断实验验证当前点模型在平坦区、敏感但平坦区、真实热点区上的表达能力。

## 1. 实验概览

### 1.1 区域定义和计算方法

区域定义来自每个 case 的 `nodes.csv`，不是训练脚本临时按坐标硬切出来的。代码会读取节点级 mask 列，并把多个细分 mask 合并成诊断区域。

| 诊断区域 | `nodes.csv` mask 来源 | 含义 |
|---|---|---|
| `center_couple_region` | `center_couple_mask` | 中心质量耦合/圆盘中心耦合附近区域 |
| `plate_hole_region` | `plate_hole_wall_mask` | 圆盘板孔孔壁区域 |
| `ear_hole_region` | `ear_hole_wall_mask` | 耳片通孔孔壁区域 |
| `ear_connection_region` | `ear_connection_fillet_mask` / `ear_connection_earside_mask` / `ear_connection_mask` | 耳片到圆盘连接区，包括连接圆角和耳片侧连接区域 |
| `other_region` | 不属于上述任一应力区域 | 全零件其他区域 |
| `stress_region_mask` | 上述应力区域 mask 的并集 | 是否位于任一标注应力集中区域 |

区域合并规则：

```text
center_couple_region = center_couple_mask
plate_hole_region = plate_hole_wall_mask
ear_hole_region = ear_hole_wall_mask
ear_connection_region = ear_connection_fillet_mask OR ear_connection_earside_mask OR ear_connection_mask
stress_region_mask = center_couple_mask OR plate_hole_wall_mask OR ear_hole_wall_mask
                     OR ear_connection_fillet_mask OR ear_connection_earside_mask OR ear_connection_mask
other_region = NOT stress_region_mask
```

距离特征计算方法：

- 对每个 case，取节点坐标 `[x, y, z]`。
- 对每个区域，取该区域 mask 为 1 的节点作为区域点集。
- 用 `cKDTree` 计算每个节点到该区域点集的最近欧氏距离。
- 距离统一除以 `plate_radius`，得到无量纲距离特征。

公式：

```text
dist_to_region(node_i) = min_j || xyz_i - xyz_j ||2,  j in region_nodes
dist_to_region_over_plate_radius = dist_to_region / plate_radius
dist_to_nearest_stress_region = min(
  dist_to_center_couple_region,
  dist_to_plate_hole_region,
  dist_to_ear_hole_region,
  dist_to_ear_connection_region
)
```

### 1.2 三类点的选点计算方法

点集选择以 `case-node` 为单位，先统计该节点在所有选中频率上的真实响应谱，再按谱形和区域 mask 选点。使用的基础统计量如下：

```text
target(f, node) = MISES_psd_density
log_value = log1p(max(target, 0))
mean_log = mean(log_value over frequency)
std_log = std(log_value over frequency)
range_log = max(log_value) - min(log_value)
mean_raw = mean(target over frequency)
max_raw = max(target over frequency)
peak_ratio = max_raw / max(mean_raw, 1e-12)
```

所有点集都会先排除：

```text
bc_mask == 1
center_node_mask == 1
valid_frequency_count == 0
```

D1 `full_flat_background`：

- 候选点：`stress_region_mask == 0`，即不在标注应力集中区域。
- 先按 `nearest_stress_distance` 取距离应力区域更远的一批背景点，当前使用 0.60 分位作为阈值。
- 再用 `std_log`、`range_log`、`peak_ratio` 的低分位筛选平坦谱，当前默认使用 0.20 分位；如果数量太少，放宽到 0.30 分位。
- 每个 case 每类点最多保留 `800` 个节点。

D2 `full_sensitive_flat`：

- 候选点：`stress_region_mask == 1`，即位于标注应力集中区域。
- 按 `center_couple_region`、`plate_hole_region`、`ear_hole_region`、`ear_connection_region` 分区分别筛选，避免某个大区域吞掉所有样本。
- 每个区域内用 `std_log`、`range_log`、`peak_ratio` 的低分位筛选真实频谱平坦点，当前默认 0.20 分位；若某区域数量小于 100，放宽到 0.30 分位。
- 每个 case 每类点最多保留 `800` 个节点。

D3 `full_hotspot`：

- 候选点：非边界、非中心点。
- 只要在任一频点进入该 frame 的 top 5% 响应节点，就作为热点候选。
- 另外，如果节点同时满足 `max_raw` 高、`std_log` 高、`peak_ratio` 高，也作为热点候选：

```text
max_raw >= 全体候选 max_raw 的 0.90 分位
std_log >= 全体候选 std_log 的 0.80 分位
peak_ratio >= 全体候选 peak_ratio 的 0.80 分位
```

- 每个 case 每类点最多保留 `800` 个节点。

### 3.1 特征设计意图

这三个实验不是重新设计一套特征，而是在 V5 主模型特征体系上加全零件区域先验。设计目标是让模型同时知道三类信息：

- 当前节点在全零件中的几何位置和相对尺度。
- 当前 case/frequency 的输入激励、模态接近程度和 FRF 响应强弱。
- 当前节点是否处在已知应力集中区域，以及离这些区域有多近。

特征分组说明：

| 特征组 | 设计目的 |
|---|---|
| 基础几何与归一化坐标 | 描述节点在圆盘/全零件中的相对位置，避免模型直接记绝对坐标尺度 |
| 耳片局部几何 | 保留 V5 对耳片孔、耳片根部、孔-根部 bridge 的先验；即使训练是全零件，耳片区域仍是重点风险区 |
| 应力区域距离特征 | 告诉模型节点到中心耦合区、板孔、耳片孔、耳片连接区的连续距离，避免只用 0/1 mask 造成边界突变 |
| 区域 mask 特征 | 明确注入 `nodes.csv` 标注区域，帮助区分 center/plate hole/ear hole/ear connection 等不同物理区域 |
| PSD 与频率特征 | 表达当前频率输入载荷强弱，以及频率本身的尺度 |
| 模态 detuning 与 ratio | 表达当前频率离模态频率有多近，解决峰值主要出现在模态附近的问题 |
| 节点振型与 FRF 特征 | 表达该节点在相关模态下是否容易响应，是预测热点位置的核心动态先验 |
| 模态梯度 proxy | 用振型空间变化近似局部应变/应力集中趋势，帮助 top1/top5 热点定位 |
| modal baseline 特征 | 给模型一个物理启发的响应强弱基线，降低从纯 MLP 学习频响形态的难度 |

连续特征使用训练集 scaler 标准化；几何距离类特征已经除以 `plate_radius`、`hole_radius` 或局部宽度等物理尺度，因此作为 normalized geometry 直接输入；mask 保持 0/1，不做标准化。

### 3.2 和 V5 主模型的特征差异

与 V5 主模型相比，诊断模型没有改变 PSD、频率、模态、FRF、模态梯度和 modal baseline 特征。真正新增的是全零件应力区域相关的 13 维：

| 类型 | 数量 | 新增内容 |
|---|---:|---|
| 区域距离 | 5 | 到中心耦合区、板孔、耳片孔、耳片连接区、最近应力区的归一化距离 |
| 区域 mask | 8 | `center_node_mask`、四类应力区 mask、耳片连接细分 mask、`stress_region_mask` |

因此三组诊断模型可以理解为：

```text
V5 动态/模态/PSD 特征
+ 全零件 nodes.csv 区域标注
+ 到关键应力区域的连续距离
+ 三类 pointset 诊断采样
```

## 6. 结果解读

### D1 平坦背景区

D1 的 test MAE 只有 85.2，说明模型能把普通背景点预测到较低响应量级。但 `within25=0.2109`，说明在低值区域按照相对误差衡量仍不稳定。由于真实值很小，少量绝对偏差也会表现为较大的相对误差。

结论：模型没有明显乱造大热点，但低响应区域的相对校准较弱。

### D2 敏感区平坦点

D2 是三组里最差的结果，`test log MAE=0.6051`，`within25=0.2088`，且 `pred/target mean=0.809`，整体偏低估。它说明“位于应力集中标注区域但真实频谱平坦”的点很难学。

`peak_relative_error=14.7998` 不宜单独作为主要判断依据，因为 D2 是平坦点实验，真实峰值可能较小，分母过小会放大该指标。

结论：如果只加强区域先验，模型仍可能无法稳定区分“几何敏感”和“真实被激发”。后续需要更强的频率-模态激发强弱特征或低响应负样本约束。

### D3 真实热点点

D3 的 test `within25=0.4132`，`peak_relative_error=0.3508`，`pred/target mean=0.975`，说明模型对真实热点有较明确的学习能力，均值校准也比 D1/D2 好。

但 `top1_log_mae=0.5397`、`top5_log_mae=0.3868` 仍偏高，最高响应点和热点形状仍是主要误差来源。

结论：当前特征能表达热点，但 top1/top5 精度还不够，后续优化应该继续围绕热点峰值和峰形。

## 7. 总体结论

- 这三个实验证明当前 V5 特征体系对真实热点有表达能力，但对平坦低值区和敏感区真实平坦点的相对稳定性不足。
- D2 是最关键的风险桶：模型需要避免把几何敏感区天然当成热点区。
- D3 说明热点方向不是完全不可学，当前主要问题是 top1/top5 极值和热点形态仍偏粗。
- 后续主模型优化不建议只继续堆几何区域先验；更值得做的是增强频率-模态激发强弱、频域连续性、低响应负样本校准，以及在评估中单独跟踪 D2 这类“敏感但平坦”的误报风险。
