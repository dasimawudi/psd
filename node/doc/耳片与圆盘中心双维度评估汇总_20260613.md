# 耳片与圆盘中心双维度评估汇总

生成日期：2026-06-13

本文统一汇总两个模型在两个维度上的算法精度，当前 top-k 全部采用 **百分比口径**：`top1% / top5% / top10% / top15% / top25%`，不是固定节点数口径。

1. `case-node-f` 逐频应力维度：评估频域曲线每个点的 `MISES_psd_density` 预测精度。
2. `case-node` 最终 RMises 维度：评估每个节点把所有频率积分后的最终 RMS 应力量级预测精度。

核心指标：

- `within25`：相对误差 `|pred - target| / |target| <= 25%` 的点占比。
- `relative MAE`：逐点相对绝对误差平均值，越小越好。
- `pred/target`：预测均值 / 真实均值，用于观察整体高估或低估。

## 背景说明：建模方式与特征构造差异

当前评估的耳片 best 和圆盘中心 `continue70_4m` 属于 `node MLP` 路线，其中 `node` 表示节点，`MLP` 是多层感知机。它把样本拆成 `(case, node, frequency)` 点级回归，分别表示工况、节点和频率；模型直接预测该点的 `MISES_psd_density`，即 von Mises 应力功率谱密度，再沿频率积分得到每个节点的最终 `RMises`，即积分后的 RMS von Mises 应力。它不显式使用网格边连接，空间关系主要依赖手工特征表达。

`node MLP` 的特征更偏“强物理先验”：除节点几何/位置、频率和 `PSD`（功率谱密度）外，还显式加入模态频率比、`detuning`（当前频率相对模态频率的偏离量）、模态振型幅值/梯度、`FRF`（频率响应函数）加权响应、区域 `mask`（区域标记）、到热点区域距离等。耳片 best 更强调耳片孔、连接圆角等应力区域距离先验；圆盘中心模型额外加入中心 `band/RBF` 特征，其中 `band` 表示中心环带/区域分段，`RBF` 是径向基函数，用于软编码到中心的距离，还加入 `center/near mask`（中心区/近中心区标记）、局部模态区域特征和 `low-rank curve head`（低秩频率曲线输出头），用于刻画中心区域频率曲线形态。

`case7_gnn` 是图场建模路线：每个 case 被构造成图，节点特征主要是 `[x, y, z, bc_mask]`，边特征是 `[dx, dy, dz, dist]`，全局特征包含 case 参数、PSD、`freq_top3` 或频率标量。模型通过 edge message passing 在有限元网格拓扑上传递信息，更强调空间连续性和邻域传播。

简要对比：`case7_gnn` 适合利用网格拓扑学习节点场，特征相对基础；当前 `node MLP` 适合逐频 PSD 回归，特征更丰富，尤其加强了频率、模态、FRF 和区域热点先验。

## 结论总览

总体看，圆盘中心模型和耳片 best 模型的优势区域不同：圆盘中心 `continue70_4m` 的整体覆盖更均衡，尤其在逐频整体和最终 RMises 整体上表现更好；耳片 best 模型的整体逐频点精度较弱，但对高响应区域，尤其最终 RMises 高应力节点的预测更稳定。

从 `case-node-f` 逐频应力维度看，圆盘中心模型 overall within25 为 82.52%，relative MAE 为 27.31%，说明它对全部逐频点的整体覆盖较好；但越靠近每帧局部高响应区越难，top1% within25 只有 36.70%，top25% within25 提升到 70.31%，top100% 等价于 overall 的 82.52%。耳片 best 模型相反，overall within25 为 59.05%，relative MAE 为 56.93%，但逐频高响应 top1% within25 达到 87.30%，relative MAE 只有 13.06%，说明它对每帧真实高响应区域的频域曲线预测更稳定。

从 `case-node` 最终 RMises 维度看，圆盘中心模型 overall within25 为 96.21%，relative MAE 为 8.45%，积分后的整体节点 RMS 应力量级预测已经很可靠；但最高 RMises 尾部仍是短板，top1% within25 为 61.14%，relative MAE 为 23.90%，扩大到 top25% 后 within25 提升到 91.44%，relative MAE 降到 11.29%。耳片 best 模型在最终 RMises 高应力区表现最稳，overall within25 为 83.65%，但 top1% within25 达到 98.55%，top25% within25 仍有 95.57%，说明它对耳片最终高 RMS 应力节点的量级预测非常可靠。

因此，如果关注整体节点覆盖和积分后的整体稳定性，圆盘中心 `continue70_4m` 当前表现更均衡；如果关注最终高应力热点的 RMises 量级，耳片 best 模型更可靠。后续优化上，圆盘中心应重点提升逐频局部高响应区和最终 RMises top1% 尾部；耳片则应主要改善低/中响应逐频点的整体覆盖。

## 口径说明

- 本文 top-k 均为百分比口径，不是固定节点数口径。
- 逐频应力维度的 top 百分比是每个 `case-frequency` frame 内真实 PSD 应力最高的 topX% 节点。
- 最终 RMises 维度的 top 百分比是每个 `case` 内真实最终 RMises 最高的 topX% 节点。
- 两个 top 百分比不完全等价：前者看频域曲线局部高响应点，后者看频率积分后的最终高 RMS 节点。
- `relative MAE` 对低 target 区域敏感；因此解释低应力分位时应结合 target 范围、within25 和 pred/target 一起看。
