# 圆盘中心优化实验结果汇总

快照时间：2026-06-13 11:25 CST  
对比基线：`node_mlp_v6_disk_center_baseline`，即此前最强的圆盘中心点模型。  
任务口径：`dataset.node_scope: disk_center`，指标字段沿用训练日志中的 `earpiece_stress_*` 命名，但实际评估的是圆盘中心点/中心区域。

## 1. 结论

- 当前收益最大的方向是 `center region features + low-rank curve head`。
- `node_mlp_v6_disk_center_low_rank_curves_fast_eval` 已完成标准 test 评估，整体 test within25 从 baseline 的 `0.5886` 提升到 `0.7553`，top1/top5/top10 within25 分别提升 `+0.1006 / +0.1537 / +0.1815`。
- `node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m` 仍在训练，当前 best epoch 49 的 val 指标继续明显优于已完成的 `fast_eval`，但标准 `test_metrics` 尚未写入，因此这里只作为 val 快照和分位 test 诊断引用。
- `hotspot_features` 单独加中心区域特征有效，但收益小于 low-rank 头。
- `calibrated_fast_eval`、`hotspot_aux_head`、`peak_calibration` 这几条偏高值/峰值校准的分支没有带来稳定收益；其中 aux/head 和 peak calibration 明显把高值区推成过预测，top-k 指标劣化。

## 2. 特征和优化差异

### 2.1 Baseline

模型：`node_mlp_v6_disk_center_baseline`

基线特征维度为 `238`：

- 几何/位置特征：`x_norm/y_norm/z_norm/r_norm/dist_to_edge/sin_theta/cos_theta` 等。
- 圆盘中心和孔边相关特征：`include_disk_center_features: true`，`include_plate_hole_features: true`。
- 模态/FRF 特征：`include_shape_normalized_mode_features`、`include_modal_ratio_features`、`include_modal_frf_features`、`include_modal_frf_shape_features`、`include_modal_gradient_features`、`include_modal_baseline_feature`。
- 损失：target quantile 加权，top1/top5/sample peak 相关损失，background false peak 和 participation residual。

### 2.2 Center Region / Hotspot Features

代表模型：`node_mlp_v6_disk_center_hotspot_features`

相对 baseline 增加到 `267` 维，新增 29 个中心区域相关特征：

- 11 个几何/软分区特征：`center_inner_core_soft`、`center_mid_ring_soft`、`center_outer_ring_soft`、`center_region_rbf_0` 到 `center_region_rbf_7`。
- 18 个中心区域模态聚合特征：inner/outer 的 `mean/max log nearest_umag`、`weighted_umag_frf`、`weighted_grad_umag_max_frf`，以及 outer-minus-inner 差分。
- 配置开关：`include_disk_center_band_features`、`include_disk_center_rbf_features`、`include_disk_center_modal_region_features`。
- 初始化：从 baseline checkpoint 继续训练。

收益：特征本身有效，test overall within25 提升 `+0.0751`，top1/top5/top10 within25 提升 `+0.0441 / +0.0634 / +0.0804`。

### 2.3 Low-Rank Curve Head

代表模型：`node_mlp_v6_disk_center_low_rank_curves_fast_eval`

在 center region features 基础上增加结构约束：

- `low_rank_curve_head: true`
- `center_curve_rank: 3`
- `center_residual_weight: 0.1`
- 初始化：从 `node_mlp_v6_disk_center_hotspot_features/best.pt` 继续训练。

收益：这是目前完成 test 的最强方案。相比 baseline，test overall within25 提升 `+0.1667`，top1/top5/top10 within25 提升 `+0.1006 / +0.1537 / +0.1815`；overall log MAE 下降 `0.1042`。

### 2.4 Continue70 + 4M Batch

代表模型：`node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m`

在 `low_rank_curves_fast_eval` 基础上继续训练：

- `epochs: 70`
- `batch_size: 4194304`
- `sample_batch_size: 128`
- `init_checkpoint: node/outputs/node_mlp_v6_disk_center_low_rank_curves_fast_eval/best.pt`

当前状态：仍在训练，快照时 best epoch 为 49。标准 `test_metrics` 还为空，因此不能和已完成模型做最终 test 横比。

val 快照收益很大：overall within25 从 baseline val `0.5696` 到 `0.8099`，top1/top5 within25 从 `0.2267/0.3159` 到 `0.3796/0.5160`。已生成的 test 分位诊断里，p0 全量累计 within25 为 `0.8121`、log MAE 为 `0.1506`，p99-p100 最高 1% band within25 为 `0.7459`。

### 2.5 Peak / Calibration Loss

代表模型：`node_mlp_v6_disk_center_low_rank_curves_calibrated_fast_eval`、`node_mlp_v6_disk_center_peak_calibration`

新增/强化损失项：

- `disk_center_peak_loss_weight: 0.35`
- `disk_center_top5_loss_weight: 0.3`
- `disk_center_top1_loss_weight: 0.55`
- `disk_center_top1_under_weight: 0.9`
- `disk_center_top5_under_weight: 0.5`
- `center_curve_consistency_weight: 0.02` 仅在 calibrated fast eval 分支中启用。

结果：该方向没有超过 low-rank 主线。`calibrated_fast_eval` 相比 baseline overall 有提升，但 top5 log MAE 反而变差；`peak_calibration` 则整体和 top-k 都明显劣于 baseline，主要表现为高响应区过预测。

### 2.6 Hotspot Aux Head

代表模型：`node_mlp_v6_disk_center_hotspot_aux_head`

新增辅助头和辅助损失：

- `hotspot_aux_heads: true`
- `use_hotspot_aux_heads: true`
- `hotspot_aux_top1_quantile: 0.99`
- `hotspot_aux_top5_quantile: 0.95`
- `aux_top1pct_loss_weight: 0.35`
- `aux_top5pct_loss_weight: 0.2`
- `aux_top1pct_pos_weight: 32.0`
- `aux_top5pct_pos_weight: 12.0`

结果：当前不成立。test overall within25 低于 baseline `-0.0439`，top1/top5/top10 within25 分别低 `-0.0591 / -0.1489 / -0.1366`，高值区 pred/target 明显大于 1。

## 5. 分模型判断

### `node_mlp_v6_disk_center_hotspot_features`

特征收益明确。新增中心软分区、RBF 和中心区域模态聚合后，overall、top1、top5、top10 都比 baseline 好。它适合作为后续结构优化的基础 checkpoint，但不是当前最强。

### `node_mlp_v6_disk_center_low_rank_curves_fast_eval`

当前已完成 test 的最佳模型。低秩频响头能有效利用中心区域曲线低秩结构，尤其显著改善 top5/top10。建议作为当前可交付的圆盘中心模型。

### `node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m`

当前最有潜力的在训模型。val 指标已经远好于 `fast_eval`，且 test 分位诊断也显示整体 within25 很高。需要等训练结束后重新跑标准 test metrics，再决定是否替代 `fast_eval` 作为最终 best。

### `node_mlp_v6_disk_center_low_rank_curves_calibrated_fast_eval`

相比 baseline 有收益，但相比 `low_rank_fast_eval` 明显退化。校准/峰值强化把预测推高，top5 log 变差，说明额外峰值损失当前权重过强或方向不稳定。

### `node_mlp_v6_disk_center_hotspot_aux_head`

不建议继续沿当前配置推进。辅助头和高 pos weight 导致高响应区过预测，top1/top5 within25 明显低于 baseline。

### `node_mlp_v6_disk_center_peak_calibration`

当前配置失败。整体 within25、top-k within25 和 log MAE 都比 baseline 差，主要问题同样是峰值/高响应区过预测。

## 6. 后续建议

1. 以 `node_mlp_v6_disk_center_low_rank_curves_fast_eval` 作为当前稳定 best。
2. 等 `node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m` 训练完成后，补跑标准 test metrics，并更新本文档第 3、4 节。
3. 保留 center region features 和 low-rank curve head；暂时不要合入 `hotspot_aux_head` 和当前 `peak_calibration` 的损失配置。
4. 如果继续做峰值优化，建议从 `low_rank_fast_eval` 出发，降低 top1/top5 under/peak loss 权重，并增加对 pred/target 过预测的约束。
