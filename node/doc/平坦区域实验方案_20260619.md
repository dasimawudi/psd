# 平坦区域实验方案

## 背景与动机

当前模型在训练时使用 `fullpart_region`、`disk_center_region`、`earpiece_region` 等空间区域划分来评估拟合效果。但这些区域的 PSD 值分布差异极大（横跨 19 个数量级，1e-9 ~ 3e10），导致无法区分拟合误差的来源：

- **PSD 量级因素**：大值主导 loss，小值区域天然拟合更差
- **几何/物理复杂性因素**：应力集中区域（耳片孔边、中心加载点）的应力场本身更复杂

**核心假设**：如果排除 PSD 量级的混淆，模型在简单几何区域（远离应力集中处）的拟合应该显著优于复杂区域。

---

## 方案 A：按 PSD 值分桶评估（虚拟区域）

### 思路

不定义空间区域，而是**按目标 PSD 值的大小将对评估点分桶**，每个桶内的 PSD 值处于同一量级，因此排除了"大值主导"的混淆。

### 具体做法

1. 在 eval 阶段，对每个样本的 (node, freq) 点，按 target PSD 值分配到预定义的 log-spaced 区间（如 `[1, 10)`, `[10, 100)`, `[100, 1000)`, ...）
2. 每个桶内独立计算相对误差（MAPE / RMSE / R²）
3. 输出一张分桶误差曲线图：X 轴 = PSD 区间，Y 轴 = 相对误差

### 优点

- 完全排除 PSD 量级混淆，每个桶内 PSD 可比
- 实现成本低，只需修改 eval 的 metric reporter，不涉及训练流程
- 可以直接复用已有推理结果

### 缺点

- 如果某个桶内样本太少（极值区间），结果不够可靠
- 不能区分"同一 PSD 量级下，不同空间位置的拟合差异"

### 实现量

约 0.5 天：在 eval 流程中加一个按 target 分桶的 error breakdown。

---

## 方案 B：空间低方差区域

### 思路

在空间上找一块**逐节点 PSD 方差最小**的连通区域，作为"平坦区域"评估集。

### 具体做法

1. 加载 N 个训练 case（如 100 个），对每个节点 ID，收集该节点在所有 case、所有频率下的 PSD 值
2. 计算每个节点的变异系数 CV = std / mean（或直接用 std）
3. 取 CV 最低的前 K%（如前 20%）节点作为"平坦区域"
4. 可选：对选出的节点做空间连通性过滤，只保留最大连通分量的邻域

### 优点

- 物理含义直观：确实是"应力变化不大的区域"
- 是实际的空间区域，可以直接用作训练/评估的 mask

### 缺点

- 低方差区域天然就是低应力区域（PSD 绝对值小），又与 PSD 量级混淆
- 实现成本较高，需要扫描大量训练数据

### 实现量

约 1 天：数据扫描 + 统计分析 + 连通性过滤。

---

## 方案 C：组合方案 —— 先分桶，再按空间分组（推荐）

### 思路

综合 A 和 B，两层控制变量：

1. 选一个**狭窄的 PSD 区间**（比如 PSD ∈ [100, 200] 或 [1000, 2000]）
2. 在这个区间内，把样本点按空间区域分组：
   - disk_center_region
   - earpiece_region
   - flat_region（= fullpart - disk_center - earpiece，即"背景区"）
3. 对比**同一 PSD 量级下，不同空间区域的相对误差**

### 示意图

```
                   PSD ∈ [100, 200]
                  ┌─────────────────┐
                  │  disk_center    │  → MAPE = 12%
                  ├─────────────────┤
                  │  earpiece       │  → MAPE = 18%
                  ├─────────────────┤
                  │  flat (背景区)   │  → MAPE = 5%
                  └─────────────────┘
```

### 诊断矩阵

| 现象 | 结论 |
|------|------|
| 同一 PSD 区间内，3 个区域误差接近 | PSD 量级是主导因素，模型对几何差异不敏感 |
| flat 区域误差最低，earpiece 最高 | 几何复杂性主导误差，模型没学到复杂几何特征 |
| disk_center 误差最高 | 中心加载点的应力场最难拟合 |
| 所有区域误差都大 | 模型容量/训练不足，与区域无关 |

### 优点

- 干净分离了两个混淆因素（PSD 量级 × 几何复杂性）
- 用现有 mask 即可实现（flat_region = ~earpiece & ~disk_center）
- 结论直接支持下一步优化方向

### 缺点

- 需要 PSD 区间有足够的样本覆盖三个区域
- 单个区间可能不够，需要多选几个区间交叉验证

### 实现量

约 0.5-1 天：eval 中加 target 分桶 + region mask 交叉分组统计，输出表格和对比图。

---

## 建议执行顺序

1. **先做方案 A**（最快，0.5 天），跑一张分桶误差曲线，建立基线认知
2. 如果发现某些 PSD 区间误差特别大，**再做方案 C**，在这些区间内对比不同空间区域
3. 方案 B 作为补充——如果方案 C 发现几何差异确实重要，再找真正的低方差区域做更严格的验证

## 待确认问题

1. 方案 A/C 中，评估指标用 MAPE、RMSE 还是相对 RMSE（RMSE / mean_target）？建议 MRMSE（mean-normalized RMSE），兼顾量级差异和可解释性
2. flat_region 的几何定义：是用 `~earpiece & ~disk_center`（背景磁盘区），还是用 `~all_stress_regions`（排除所有应力热点）？
3. PSD 分桶的区间划分：按 log10 等宽（每 10 倍一个桶），还是按数据分位数（保证每桶样本量均衡）？
