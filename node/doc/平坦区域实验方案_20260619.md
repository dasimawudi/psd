# 平坦区域实验方案与结果

> 更新时间：2026-06-24
> 状态：已完成 3 个 100 epoch 平坦目标区间模型训练与 test 集评估

## 实验目的

这次实验的目标不是继续比较原始空间区域里的绝对误差，而是先控制目标值量级，只看 `MISES_psd_density` 落在同一平坦目标区间内时，不同数据范围的模型表现。

核心问题：

- 在目标值区间固定后，耳片、圆盘、全量平坦区的拟合难度是否仍然不同？
- 高响应点的相对误差是否明显优于整体点？
- 继续优化时应该优先处理哪个区域的数据或特征表达？

本轮结果不再把 raw MAE 作为主指标。主要指标使用：

- `within25`：相对误差 `abs(pred - target) / abs(target) <= 25%` 的点占比。
- `相对 MAE`：逐点相对误差均值。
- `相对 log MAE`：`log1p(MISES_psd_density)` 空间里的 MAE，用于观察相对量级误差。

## 数据集设计

数据源：

- `dataset.root`: `.cache/mises_psd_next1000_full_export_step0p5_balanced_v1`
- `sample_mode`: `per_frequency`
- 频率范围：`20 Hz` 到 `2000 Hz`
- split：显式 case split，沿用原 v6 配置，`split_seed = 42`
- 平坦目标区间：`1e6 <= MISES_psd_density < 1e7`
- 空样本处理：`drop_empty_samples: true`，只保留当前 node scope 下至少有一个点落入目标区间的 case-frequency 帧。

本轮只做 3 个数据范围：


| 数据范围  | `dataset.node_scope` | 含义                                |
| ----- | -------------------- | --------------------------------- |
| 耳片平坦区 | `earpiece`           | 只保留耳片区域内、目标值落入 `[1e6, 1e7)` 的点    |
| 圆盘平坦区 | `disk_region`        | 只保留非耳片圆盘区域内、目标值落入 `[1e6, 1e7)` 的点 |
| 全量平坦区 | `all_nodes`          | 全部节点中目标值落入 `[1e6, 1e7)` 的点        |


test 集全非空评估规模如下：


| 数据范围  | 非空 test 样本数 | test 点数   |
| ----- | ----------- | --------- |
| 耳片平坦区 | 2,694       | 1,261,309 |
| 圆盘平坦区 | 2,064       | 902,573   |
| 全量平坦区 | 2,882       | 2,163,882 |


## 模型与训练策略

三个模型都使用全量模型的特征配置，继承 `node_mlp_v6_fullpart_disk_center.yaml` 的 full features，不单独削减耳片或圆盘特征。这样可以把本轮实验重点放在数据范围和目标区间上，模型与特征评估逻辑保持不变。

模型输出目录：

- `node/outputs/node_mlp_v6_flat_target_earpiece_full_features_fast_eval_100ep`
- `node/outputs/node_mlp_v6_flat_target_disk_full_features_fast_eval_100ep`
- `node/outputs/node_mlp_v6_flat_target_fullpart_full_features_fast_eval_100ep`

主要训练配置：


| 配置项                     | 值                                                       |
| ----------------------- | ------------------------------------------------------- |
| MLP hidden dims         | `[256, 256, 128]`                                       |
| activation              | `silu`                                                  |
| dropout                 | `0.1`                                                   |
| layer norm              | `true`                                                  |
| init checkpoint         | `node/outputs/node_mlp_v6_fullpart_disk_center/best.pt` |
| epochs                  | `100`                                                   |
| early stopping patience | `100`                                                   |
| batch_size              | `2,097,152` points                                      |
| sample_batch_size       | `256`                                                   |
| lr                      | `8e-5`                                                  |
| weight_decay            | `1e-4`                                                  |


训练时采用 fast eval，避免每个 epoch 做过重评估：

- `eval_topk_mode: basic`
- `eval_max_sample_batches: 8`
- `final_test_max_sample_batches: 8`

训练完成后，额外对 test 集非空样本做了一次全量 top 百分比评估，结果保存到：

- `node/outputs/flat_target_top_percent_relative_eval_100ep/test_top_percent_relative_metrics.csv`
- `node/outputs/flat_target_top_percent_relative_eval_100ep/test_top_percent_relative_metrics.json`

## 评估口径

`top1% / top5% / top10% / top25%` 不是 topK 个点，而是 topK 百分比占比。

具体定义：对每个 case-frequency 帧，在当前数据范围和目标区间过滤后的节点内，按真实 `MISES_psd_density` 从大到小排序，取 `rank / node_count <= 1% / 5% / 10% / 25%` 的累计高响应点，再汇总所有帧计算指标。

## Overall 结果

这里的 overall 指标来自全非空 test 样本，和 top 百分比评估使用同一批样本。


| 模型    | best epoch | test 非空样本 | test 点数   | overall within25 | overall 相对 MAE | overall 相对 log MAE |
| ----- | ---------- | --------- | --------- | ---------------- | -------------- | ------------------ |
| 耳片平坦区 | 100        | 2,694     | 1,261,309 | 68.99%           | 25.03%         | 0.2146             |
| 圆盘平坦区 | 100        | 2,064     | 902,573   | 59.84%           | 33.53%         | 0.2680             |
| 全量平坦区 | 100        | 2,882     | 2,163,882 | 63.30%           | 29.55%         | 0.2444             |


结论上，耳片平坦区整体最好，圆盘平坦区整体最差，全量平坦区介于两者之间。说明即便把目标值限制在 `[1e6, 1e7)`，区域或几何差异仍然会影响拟合难度。

## 总结

本轮实验支持两个判断：

1. 目标值量级不是唯一误差来源。即使只看 `1e6` 到 `1e7` 的平坦目标区间，耳片、圆盘、全量三类数据仍有明显差异。
2. 高响应 top 百分比点比 overall 更容易控制在 25% 相对误差内，尤其是耳片和全量模型；圆盘区域仍是主要短板。

下一步建议：

- 如果目标是提升全局可用性，应优先分析圆盘平坦区误差来源，尤其是 top10%-top25% 这段扩展后误差明显变大的区域。
- 如果目标是先保证高响应点可靠性，耳片和平坦全量模型已经给出较好的 top5% 基线，可以在这个口径上继续做特征或 loss 微调。
- 后续报告中建议继续使用 `within25 + 相对 MAE + 相对 log MAE`，不要用 raw MAE 做主要比较指标。
