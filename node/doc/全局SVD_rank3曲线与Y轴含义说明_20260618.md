# 全局 SVD rank3 曲线与 y 轴含义说明

本文说明 `800` 个训练 case 放在一起做全局 SVD 后得到的 rank3 曲线是什么，以及图中的 y 轴应该如何理解。

相关输出目录：

- `node/outputs/node_mlp_v6_disk_center_global_low_rank_train_all/`

主要图文件：

- `train_global_rank3_basis_only.png`
- `train_global_rank3_log_contribution_only.png`
- `train_global_rank3_curves_only.png`

主要数据文件：

- `train_global_svd_basis.csv`
- `train_global_low_rank_summary.json`

## 1. 这次全局 SVD 的数据口径

这次分析不是“每个 case 单独做 SVD”，而是把所有训练 case 放在一起，做一次全局 SVD。

数据构造方式如下：

1. 使用 train split 的全部 `800` 个 case。
2. 每个 case 选圆盘中心区域中峰值响应最高的最多 `512` 个节点。
3. 每个节点在不同频率下形成一条真实目标响应曲线。
4. 原始 target 先做：

   ```text
   log1p(target)
   ```

5. 因为不同 case 的频率点不完全一致，所以把每条曲线插值到统一的 `20Hz - 2000Hz` log-frequency 网格。
6. 统一网格大小为 `512` 个频率点。
7. 最终全局矩阵大小约为：

   ```text
   curves × frequencies = 409600 × 512
   ```

其中：

```text
409600 = 800 cases × 512 curves/case
```

## 2. 为什么需要插值

800 个 case 的原始频率网格并不一致。

检查结果显示：

```text
frame count dist = {77: 238, 96: 41, 115: 502, 134: 19}
```

也就是说，不同 case 可能有 `77`、`96`、`115` 或 `134` 个频率帧。

而且每个 case 的具体频率点也不同。所有 case 精确共有的频率点只有：

```text
20Hz
2000Hz
```

所以如果要把所有 case 放在一起形成一个统一矩阵，必须先插值到同一个频率网格。否则不同曲线的列无法对齐。

## 3. SVD 分解的对象

设全局曲线矩阵为：

```text
X ∈ R^(N × F)
```

其中：

```text
N = 409600  # 曲线数量
F = 512     # 统一频率点数量
```

每一行是一条节点响应曲线：

```text
x_i(f) = log1p(target_i(f))
```

在做 SVD 前，对每条曲线先去掉自己的平均值：

```text
x_i_centered(f) = x_i(f) - mean_f(x_i(f))
```

然后再去掉全局频率方向的平均值：

```text
X_centered = row_centered - column_mean
```

最后对中心化后的矩阵做 SVD：

```text
X_centered = U Σ V^T
```

其中：

- `U`：每条曲线在各个 rank 分量上的系数。
- `Σ`：奇异值，表示每个 rank 分量解释的能量大小。
- `V^T`：频率方向的基函数，也就是图里画出来的 SVD basis。

## 4. 800 个 case 全局 SVD rank3 曲线的计算过程

这一节说明这三条全局 rank3 曲线是如何从 `800` 个训练 case 中一步一步计算出来的。

核心目标是把所有 case 的圆盘中心节点响应曲线整理成一个统一矩阵：

```text
X ∈ R^(409600 × 512)
```

然后对这个矩阵做 SVD，取频率方向的前三个右奇异向量作为全局 rank3 曲线。

实际程序中没有把完整的 `409600 × 512` 大矩阵一次性保存下来，而是逐 case 累积统计量，最后通过 `512 × 512` 的 Gram 矩阵求出同样的右奇异向量。这样内存更稳定，计算结果等价于对完整矩阵做 SVD。

### 4.1 每个 case 先构造节点响应曲线矩阵

对每个训练 case，先读取该 case 在所有频率帧下的圆盘中心节点 target。

对一个 case，可以构造一个原始矩阵：

```text
R_c ∈ R^(nodes_c × frames_c)
```

其中：

- `c` 表示第 `c` 个 case。
- `nodes_c` 是该 case 中被选中的圆盘中心节点数量。
- `frames_c` 是该 case 的频率帧数量，可能是 `77`、`96`、`115` 或 `134`。
- `R_c[j, t]` 表示该 case 第 `j` 个节点在第 `t` 个频率帧下的原始 target。

构造时会做几件事：

1. 根据配置筛选圆盘中心区域节点。
2. 对每个频率帧读取该频率下所有节点的 target。
3. 将 target 对齐到统一节点顺序。
4. 对 target 应用下限截断 `target_floor`，避免极小值或无效值影响 log 空间。
5. 把 NaN、正负无穷等异常值替换为 `0`。

这一步得到的是还没有取 log、还没有插值的原始响应矩阵。

### 4.2 每个 case 只保留最多 512 条代表性节点曲线

每个 case 的圆盘中心节点可能多于 `512` 个。为了让所有 case 的曲线数量一致，并聚焦主要响应区域，程序会按每个节点的频率峰值进行排序。

对第 `j` 个节点，先计算它在所有频率下的峰值：

```text
peak_j = max_t R_c[j, t]
```

然后选择峰值最大的最多 `512` 个节点：

```text
keep = top512 nodes by peak_j
```

保留下来的矩阵记为：

```text
R_c_keep ∈ R^(512 × frames_c)
```

如果某个 case 可用节点少于 `512` 个，则保留实际数量。

这一步的含义是：每个 case 主要贡献圆盘中心区域中响应较强、对建模更关键的节点曲线。

### 4.3 转换到 log1p(target) 空间

保留节点后，对原始 target 做：

```text
A_c = log1p(R_c_keep)
```

也就是：

```text
A_c[j, t] = log(1 + R_c_keep[j, t])
```

这样做有几个作用：

- 压缩极大响应值的动态范围。
- 让乘法量级差异更接近加法差异。
- 降低少数极大峰值对 SVD 的支配。
- 和模型训练中的 target 变换保持一致。

此时矩阵形状仍然是：

```text
A_c ∈ R^(512 × frames_c)
```

但它已经处在 `log1p(target)` 空间，不再是原始 target 空间。

### 4.4 插值到统一频率网格

不同 case 的频率帧数量和具体频率点并不一致，不能直接拼成一个全局矩阵。

所以程序先构造统一频率网格：

```text
20Hz 到 2000Hz
log-spaced
512 个频率点
```

记为：

```text
f_grid = [f_1, f_2, ..., f_512]
```

然后把每个 case 的 `A_c` 从自己的原始频率点插值到这个统一网格上：

```text
I_c = interpolate(A_c, original_frequencies_c -> f_grid)
```

插值后的矩阵为：

```text
I_c ∈ R^(512 × 512)
```

这里第一维是节点曲线，第二维是统一频率点。

实际实现中使用的是按频率排序后的线性插值。这样所有 case 的第 `k` 列都对应同一个统一频率 `f_k`。

### 4.5 对每条曲线做行中心化

插值后，每一行是一条节点响应曲线：

```text
I_c[j, :]
```

程序先去掉每条曲线自己的均值：

```text
B_c[j, f] = I_c[j, f] - mean_f(I_c[j, f])
```

也就是对每个节点单独做：

```text
row_mean_j = 该节点曲线在全部频率点上的平均 log 响应
B_c[j, :] = I_c[j, :] - row_mean_j
```

这一步的作用是去掉每个节点自己的整体高低水平，让 SVD 重点分析“随频率变化的形状”，而不是先被某些节点整体响应更大这件事主导。

因此，行中心化后的曲线更关注：

- 峰值出现在哪些频率。
- 峰宽如何变化。
- 频率响应形状如何变化。
- 不同节点曲线之间的相对形状差异。

而不是只关注：

- 哪个节点整体 target 更大。

### 4.6 把 800 个 case 合并成全局矩阵

对所有 `800` 个训练 case 都做完上面的步骤后，可以把所有行中心化后的曲线按行拼接：

```text
X_row_centered =
[
  B_1
  B_2
  ...
  B_800
]
```

如果每个 case 保留 `512` 条曲线，则总曲线数是：

```text
N = 800 × 512 = 409600
```

统一频率点数是：

```text
F = 512
```

所以理论上的全局矩阵是：

```text
X_row_centered ∈ R^(409600 × 512)
```

每一行表示：

```text
某个 case、某个节点，在 512 个统一频率点上的 log1p(target) 形状变化曲线
```

每一列表示：

```text
所有节点曲线在某个统一频率点上的 log 响应形状值
```

### 4.7 再做全局列中心化

行中心化去掉了每条曲线自己的平均值，但不同频率点上仍然可能存在全局平均偏移。

所以程序继续计算全局频率方向均值：

```text
column_mean(f) = mean_i X_row_centered[i, f]
```

然后做列中心化：

```text
X_centered[i, f] = X_row_centered[i, f] - column_mean(f)
```

最终用于 SVD 的矩阵是：

```text
X_centered ∈ R^(409600 × 512)
```

这一步的作用是去掉所有曲线共同拥有的频率平均模式，使 SVD 主要解释曲线族中的变化量。

### 4.8 SVD 的数学分解

对中心化后的全局矩阵做 SVD：

```text
X_centered = U Σ V^T
```

各个矩阵的形状是：

```text
X_centered ∈ R^(N × F) = R^(409600 × 512)
U          ∈ R^(N × F)
Σ          ∈ R^(F × F)
V^T        ∈ R^(F × F)
```

其中：

- `U` 的每一行对应一条节点曲线在各个 SVD 分量上的系数。
- `Σ` 的对角线是奇异值 `S1, S2, ..., S512`。
- `V^T` 的每一行是一个频率方向基函数。

也可以写成逐分量求和形式：

```text
X_centered[i, f] ≈
    u_i1 * S1 * v1(f)
  + u_i2 * S2 * v2(f)
  + u_i3 * S3 * v3(f)
  + ...
```

其中：

- `i` 表示第 `i` 条节点曲线。
- `f` 表示频率点。
- `v1(f)、v2(f)、v3(f)` 就是前三条全局 SVD 频率基函数。

rank3 近似就是只保留前三项：

```text
X_rank3[i, f] =
    u_i1 * S1 * v1(f)
  + u_i2 * S2 * v2(f)
  + u_i3 * S3 * v3(f)
```

这就是“全局 SVD rank3”的数学含义。

### 4.9 实际程序如何避免直接存储大矩阵

完整矩阵 `X_centered` 的大小是：

```text
409600 × 512
```

它不算特别大，但直接保存和分解仍然没必要。因为我们最终只需要频率方向的基函数，也就是 `V`。

SVD 和 Gram 矩阵之间有一个重要关系：

```text
X_centered = U Σ V^T
```

两边左乘 `X_centered^T`，可以得到：

```text
X_centered^T X_centered = V Σ^2 V^T
```

也就是说：

- `X_centered^T X_centered` 的特征向量就是 `V`。
- `X_centered^T X_centered` 的特征值就是奇异值平方 `S^2`。

因此，只要能得到：

```text
G = X_centered^T X_centered
```

就可以通过特征分解得到频率方向的 SVD basis。

实际程序逐 case 累积两个量：

```text
column_sum += B_c.sum(axis=0)
gram       += B_c.T @ B_c
```

其中：

- `B_c` 是该 case 插值后并做过行中心化的矩阵。
- `column_sum` 用来计算全局列均值。
- `gram` 是未做列中心化前的 `X_row_centered^T X_row_centered` 累积。

所有 case 处理完后，先计算：

```text
column_mean = column_sum / N
```

然后把列中心化的影响补到 Gram 矩阵里：

```text
centered_gram = gram - N * outer(column_mean, column_mean)
```

这等价于直接构造 `X_centered` 后再计算：

```text
centered_gram = X_centered^T X_centered
```

最后对 `centered_gram` 做特征分解：

```text
centered_gram = V Λ V^T
```

其中：

```text
Λ = Σ^2
S_k = sqrt(λ_k)
```

所以：

- 特征向量 `V[:, k]` 就是第 `k` 条频率方向 SVD basis。
- 奇异值 `S_k` 是第 `k` 个分量的强度。

程序会按特征值从大到小排序：

```text
λ1 >= λ2 >= λ3 >= ...
```

然后取前三个特征向量：

```text
v1(f), v2(f), v3(f)
```

这就是最终画出来的全局 SVD rank3 曲线。

### 4.10 rank3 覆盖率如何计算

SVD 中每个分量解释的能量等于奇异值平方：

```text
energy_k = S_k^2 = λ_k
```

总能量为：

```text
total_energy = Σ_k λ_k
```

rank3 覆盖率就是前三个分量解释的能量占比：

```text
rank3_explained =
    (λ1 + λ2 + λ3) / (λ1 + λ2 + ... + λ512)
```

在当前 `800` 个训练 case 全局 SVD 中，计算结果是：

```text
rank1 explained = 0.6671
rank2 explained = 0.8130
rank3 explained = 0.8792
```

这里的 `0.8792` 表示：

```text
只用三条全局固定频率 basis，
可以解释全部 409600 条中心化 log 响应曲线中约 87.92% 的变化能量。
```

它不是误差指标，也不是 within25 指标，而是 SVD 能量解释率。

### 4.11 输出到图和 CSV 的内容

最终输出的 CSV 是：

```text
train_global_svd_basis.csv
```

里面每一行对应一个统一频率点，主要列包括：

```text
frequency_hz
basis_1
basis_2
basis_3
basis_4
basis_5
singular_value_1
singular_value_2
singular_value_3
singular_value_4
singular_value_5
```

其中：

- `basis_1/basis_2/basis_3` 是前三个右奇异向量，也就是 rank3 曲线本身。
- `singular_value_1/2/3` 是对应分量的奇异值。
- 画 `Global right singular vector` 图时，直接画 `basis_k`。
- 画 `S / sqrt(N) * basis` 图时，画 `singular_value_k / sqrt(409600) * basis_k`。

所以，这三条曲线的来源可以概括为：

```text
800 个训练 case
-> 每 case 选最多 512 条圆盘中心高响应节点曲线
-> target_floor
-> log1p(target)
-> 插值到统一 512 点 log-frequency 网格
-> 每条曲线去均值
-> 全局频率列去均值
-> 累积 X^T X
-> 特征分解得到 V
-> 取 V 的前三列作为全局 rank3 曲线
```

## 5. rank3 曲线是什么

所谓 rank3 曲线，就是 `V^T` 里的前三个频率方向基函数：

```text
v1(f)
v2(f)
v3(f)
```

它们不是某三个真实节点的响应曲线，也不是模型内部 `frequency_head` 直接输出的三条曲线。

它们是全局训练集中所有圆盘中心目标曲线在 SVD 意义下的前三个正交频率基。

对任意一条中心化后的曲线，rank3 近似为：

```text
x_i_centered(f) ≈ u_i1 * S1 * v1(f)
                + u_i2 * S2 * v2(f)
                + u_i3 * S3 * v3(f)
```

如果要还原到 `log1p(target)` 曲线，还需要加回：

```text
该曲线自己的均值
全局频率方向均值
```

所以单独看 `v1/v2/v3` 时，它们只是“形状基”，不是完整响应曲线。

## 6. 第一种 y 轴：Global right singular vector

图：

```text
train_global_rank3_basis_only.png
```

y 轴名称：

```text
Global right singular vector
```

这个 y 值表示右奇异向量 `v_k(f)` 的值。

更具体地说，它表示 SVD 分解后，频率方向上的基函数本身：

```text
basis_k(f) = v_k(f)
```

这里的 `basis_k(f)` 是一个纯数学意义上的单位范数基函数。它回答的问题是：

```text
第 k 个 rank 分量主要沿着哪些频率位置变化？
```

它不回答：

```text
这个频率处的真实应力有多大？
这个频率处的预测值有多大？
这个频率处的 Mises PSD 有多大？
```

它满足单位范数约束：

```text
sum_f v_k(f)^2 = 1
```

也就是：

```text
sum(basis_k(f)^2 over all frequency grid) = 1
```

因此它没有直接物理单位，也不能直接拿来和原始 `target` 的数值大小比较。

需要特别注意：这个归一化约束会把整条曲线的平方和固定为 `1`。所以图里的 y 轴高低主要受“归一化后的相对形状”影响，而不是物理幅值影响。

它不能解释为：

- Mises 应力大小
- PSD 密度大小
- 预测值
- log target 的绝对值

它只能解释为：

```text
第 k 个全局 SVD 分量在不同频率位置上的相对形状
```

也可以更直观地说：

```text
basis 图看形状，不看物理幅值。
```

例如：

- y 值为正：这个 rank 分量在该频率处贡献方向为正。
- y 值为负：这个 rank 分量在该频率处贡献方向为负。
- 绝对值大：这个频率点对该 rank 分量更重要。
- 绝对值小：这个频率点对该 rank 分量影响较弱。

需要注意：SVD 的符号本身是任意的。

也就是说：

```text
v_k(f)
```

和：

```text
-v_k(f)
```

在数学上是等价的，只要对应的 `U` 也同时取反。因此不要过度解读正负号本身，应主要看峰位、形状和相对变化。

## 7. 第二种 y 轴：S / sqrt(N) * basis

图：

```text
train_global_rank3_log_contribution_only.png
```

y 轴名称：

```text
S / sqrt(N) * basis
```

这里：

```text
S = 当前 rank 分量的奇异值
N = 曲线总数 = 409600
basis = 对应的右奇异向量 v_k(f)
```

这个 y 值的含义是：

```text
该 rank 分量在 log1p(target) 空间中的典型贡献幅度
```

它已经不只是单位范数的形状基，而是把该 rank 分量在数据中的强弱也乘了进去。

换句话说：

```text
Global right singular vector
```

只看 `basis` 的形状；

```text
S / sqrt(N) * basis
```

看这个 `basis` 在一条典型曲线上大约能贡献多大的 `log1p(target)` 变化。

为什么要乘 `S`？

因为 `basis` 本身是单位范数，只表达形状，不表达能量大小。奇异值 `S` 才表示这个分量在数据中有多强。

为什么要除以 `sqrt(N)`？

因为 `U` 的每一列也是单位范数。对于很多曲线而言，一个典型曲线的系数量级大约是：

```text
1 / sqrt(N)
```

所以：

```text
S / sqrt(N) * basis
```

可以近似看成“典型曲线上这个 rank 分量的 log 响应贡献量级”。

因此这张图比单纯的 `basis` 图更适合判断：

- rank1、rank2、rank3 哪个分量贡献更大。
- 某个分量在哪些频段对 log 响应影响更强。
- 这个分量的典型影响是 `0.1` 量级、`1` 量级，还是更大。

但它仍然不是原始 Mises PSD，也不是某个真实节点的完整响应曲线。

## 8. y 值与原始 target 的关系

这个 y 值仍然不是原始 Mises PSD。

它处在：

```text
log1p(target)
```

空间中。

也就是说，`S / sqrt(N) * basis` 的 y 值应当理解为：

```text
log 响应的变化量
```

而不是：

```text
原始应力值
原始 PSD 值
原始 target 值
```

如果某个频率处典型 log contribution 为：

```text
y = 1
```

大致表示 `log1p(target)` 增加 `1`。

对于较大的 target，可以近似理解为原始尺度乘以：

```text
e^1 ≈ 2.718
```

如果：

```text
y = -1
```

则大致相当于原始尺度除以：

```text
e^1 ≈ 2.718
```

所以可以粗略理解为：

```text
y =  1  -> 原始尺度上约乘以 2.7
y = -1  -> 原始尺度上约除以 2.7
y =  0  -> 该 rank 分量在此频率处没有典型 log 增减
```

这个解释只适合较大的 target，并且只是量级理解。严格地说，原始尺度和 log 空间的关系是：

```text
target = exp(log1p(target)) - 1
```

因此当 target 很小时，不能简单地把 `log1p` 的加减完全等同于原始尺度的倍数变化。

还需要注意：这只是对单个 rank 分量的典型贡献解释，不是完整响应。

完整响应还需要：

```text
曲线均值
全局频率均值
多个 rank 分量
该具体节点/曲线的 U 系数
```

更完整地写，一条具体曲线的中心化 rank3 近似是：

```text
x_i_centered(f) ≈ u_i1 * S1 * v1(f)
                + u_i2 * S2 * v2(f)
                + u_i3 * S3 * v3(f)
```

其中 `u_i1/u_i2/u_i3` 是这条具体曲线自己的左奇异向量系数。不同节点、不同 case 的这些系数不同，所以同一组三条 basis 会组合出不同的曲线。

如果要回到原始的 `log1p(target)`，还需要加回均值项：

```text
x_i(f) ≈ row_mean_i
       + column_mean(f)
       + u_i1 * S1 * v1(f)
       + u_i2 * S2 * v2(f)
       + u_i3 * S3 * v3(f)
```

如果进一步回到原始 target 空间，还要做：

```text
target_i(f) ≈ exp(x_i(f)) - 1
```

因此：

- `basis` 图不是完整预测曲线。
- `typical log contribution` 图也不是完整预测曲线。
- 真实曲线必须乘以每个节点/样本自己的系数，再加回均值项。

## 9. 这些曲线和随机振动物理过程的关系

这些 rank3 曲线和随机振动物理过程有关系，但不是“一条 SVD 曲线等于一个物理模态”这种直接关系。

更准确地说：

```text
这些曲线有物理来源，但不是物理实体。
它们是随机振动响应曲线族中的主要数学变化模式。
```

### 9.1 为什么说它们有物理来源

这几条曲线不是凭空生成的，也不是人为指定的函数。它们来自真实训练数据中的圆盘中心响应曲线。

每条原始曲线本质上是一个节点在随机振动载荷下，随频率变化的响应结果。这个响应结果受随机振动物理过程控制。

在线性随机振动问题中，可以粗略理解为：

```text
节点响应 PSD(f) ≈ 输入 PSD(f) × 结构传递函数强度 |H_node(f)|^2
```

其中：

- `输入 PSD(f)` 描述外部随机激励在不同频率上的能量分布。
- `H_node(f)` 描述结构从输入到该节点响应的频率传递关系。
- `|H_node(f)|^2` 在模态频率附近通常会出现放大。
- 不同节点的响应差异还和模态振型、节点位置、局部结构形态有关。

因此，真实响应曲线中的峰值、峰宽、峰位移动和局部增强，通常和下面这些物理因素有关：

- 输入 PSD 在某些频率处更强。
- 结构模态频率附近发生响应放大。
- 阻尼控制共振峰的宽度和尖锐程度。
- 该节点在某些模态上的振型参与更强。
- 不同 case 的模态频率、PSD 峰位、PSD 峰宽发生变化。
- 圆盘中心、外环热点等不同区域的节点参与模式不同。

SVD 是在这些真实响应曲线上做的分解，所以它提取出的主要变化方向必然带有这些物理过程留下的统计痕迹。

### 9.2 为什么又不能把它们当成物理实体

虽然这些曲线来自物理响应数据，但 SVD 本身是数学正交分解。

SVD 分量必须满足数学上的正交性，而真实物理模态、输入 PSD 峰、节点响应形态并不一定按这种正交方式分开。

此外，做 SVD 前我们还进行了多个数据处理步骤：

```text
log1p(target)
行均值去除
列均值去除
频率插值
单位范数归一化
```

这些处理会改变曲线的绝对幅值含义，并把原始物理响应重新表示到一个中心化、归一化的数学空间里。

因此，一个 SVD rank 分量可能同时混合了多个物理因素：

- 多个结构模态的共同影响。
- 输入 PSD 的主峰和次峰。
- 峰位偏移。
- 峰宽变化。
- 不同节点区域的响应差异。
- 不同 case 的整体强弱差异。

所以不能直接说：

- rank1 就是第 1 阶模态。
- rank2 就是第 2 阶模态。
- rank3 就是某一个物理共振峰。
- 某条 SVD 曲线就是某个节点的真实应力曲线。
- 某条 SVD 曲线就是结构 FRF。

这些说法都过于直接，会把数学基函数误读成物理对象。

### 9.3 可以怎样做物理解释

比较合理的解释方式是把这些曲线看成：

```text
随机振动响应数据中的主导频率变化模式
```

例如：

- rank1 可能对应全局最主要的频率响应形状。
- rank2 可能对应主峰位置偏移、峰宽变化或第二类响应形态。
- rank3 可能对应局部共振峰增强、不同热点区域差异，或更细的曲线形态修正。

这里的“可能”很重要。SVD 本身不会告诉我们某个分量一定对应哪一个物理机制。要做物理解释，需要把 SVD 曲线和其他物理信息叠加比较。

最有价值的验证方式包括：

- 把 SVD 曲线峰位和输入 PSD 峰值频率对齐比较。
- 把 SVD 曲线峰位和结构模态频率对齐比较。
- 把 SVD 曲线峰位和 FRF 峰值频率对齐比较。
- 按热点类型，例如中心热点、外环热点，分别观察曲线形态。
- 按 case 的模态频率区间或 PSD 峰值区间分组，比较 SVD 系数分布。
- 查看每条真实曲线在 rank1/rank2/rank3 上的 `U` 系数是否和节点位置、热点类型、模态参与强弱相关。

如果 rank3 曲线的主要峰位长期贴近模态频率或输入 PSD 峰值频率，那么可以认为它确实在捕捉随机振动过程里的主导响应机制。

如果某个 rank 分量的系数在外环热点 case 中明显更大，那么它可能在表达外环区域特有的响应模式。

如果某个 rank 分量的正负系数对应主峰向左或向右移动，那么它可能在表达跨 case 的峰位偏移。

### 9.4 对当前模型理解的意义

这也解释了为什么模型里使用低秩曲线头是合理的。

随机振动响应虽然来自复杂的物理过程，但在一个具体 case 内，圆盘中心区域的曲线族往往高度相关。很多节点的响应曲线共享相似的 PSD 输入、模态频率和结构传递特征，只是在幅值、峰值强弱、局部形态上有差异。

因此，用少数几个频率方向的曲线分量，再配合节点自己的 mixing weights 和 node scale，可以有效表示大量节点曲线。

但这些分量最好是条件化的，而不是全训练集固定三条曲线。因为不同 case 的 PSD 和模态条件会改变曲线形态。

这和当前模型结构一致：

```text
frequency_head(frequency_features) 生成随 case 条件变化的曲线值
node_mixing_head(node_features)    生成每个节点自己的混合权重
node_scale_head(node_features)     生成每个节点自己的整体基准值
```

所以，SVD 曲线从物理角度说明了：

```text
圆盘中心响应曲线确实存在低维主导变化模式；
这些模式来自随机振动的 PSD、模态、FRF 和节点空间响应；
但它们应该被理解为物理响应的数学压缩表达，而不是单独的物理模态。
```

## 10. 为什么 rank3 全局解释率低于 per-case 解释率

之前每个 case 单独做 SVD 时，rank3 覆盖非常高：

```text
rank3 mean   ≈ 0.9954
rank3 median ≈ 0.9984
```

但把所有 `800` 个训练 case 放在一起，只使用一套全局 rank3 基函数时：

```text
rank3 explained = 0.8792
```

完整全局解释率如下：

| rank | explained |
| ---: | ---: |
| 1 | 0.6671 |
| 2 | 0.8130 |
| 3 | 0.8792 |
| 5 | 0.9359 |
| 10 | 0.9750 |
| 20 | 0.9923 |
| 50 | 0.9992 |

这说明：

```text
圆盘中心曲线在单个 case 内非常低秩，
但不同 case 之间的曲线族不是同一组三条固定曲线就能完全覆盖。
```

原因主要包括：

- 不同 case 的 PSD 输入不同。
- 不同 case 的模态频率不同。
- 峰值频率位置会移动。
- 同一类曲线在不同 case 中会被拉伸、平移或改变峰宽。
- 外环热点和中心热点的曲线形态存在差异。

所以全局共享 rank3 只能解释约 `87.92%`。

如果增加到 rank20，才能达到：

```text
rank20 explained = 0.9923
```

## 11. 与模型 low-rank curve head 的关系

模型中的 low-rank curve head 不是直接学习这三条固定的全局 SVD 曲线。

模型结构大致是：

```text
curve_values = frequency_head(frequency_features)
mixing_weights = softmax(node_mixing_head(node_features))

prediction ≈ node_scale
           + sum_k mixing_weight_k * curve_value_k
           + residual
```

这里的 `frequency_head` 输入的不只是频率本身，还包括：

- 当前频率
- PSD 当前频点值
- PSD 峰值信息
- 到模态频率的距离
- 模态响应相关特征
- FRF 相关特征

因此模型里的三条 curve values 是“条件化”的。

也就是说，它们会随着 case 的 PSD 和模态条件变化，而不是全训练集固定一组三条曲线。

这正好解释了为什么模型中 `rank=3` 仍然有效：

```text
全局固定 rank3 只能覆盖 87.92%，
但条件化 rank3 可以针对每个 case 生成不同的三维曲线表达，
更接近 per-case rank3 的高覆盖特性。
```

### 11.1 全局 rank3、by-case rank3 与模型曲线的差异

从覆盖率角度看，需要区分三种对象：

1. 全训练集固定 rank3。
2. 每个 case 单独做 PCA/SVD 得到的 by-case rank3。
3. 模型 low-rank curve head 输出的三条条件化曲线。

全训练集固定 rank3 是把 `800` 个训练 case 的圆盘中心曲线全部合在一起，只用同一组三条固定频率 basis 表达所有 case。当前全局解释率为：

```text
rank1 explained = 0.6671
rank2 explained = 0.8130
rank3 explained = 0.8792
```

也就是说，全局固定 rank3 只能解释全部中心化 `log1p(target)` 曲线约 `87.92%` 的变化能量。它说明全训练集确实有低维主导模式，但不同 case 之间的 PSD、模态频率、峰位和峰宽变化较大，不能靠同一组三条固定曲线完全覆盖。

by-case rank3 则是每个 case 单独做 PCA/SVD。一个 case 内部的圆盘中心节点共享相同 PSD 和结构模态条件，曲线族通常更低秩，因此 rank3 覆盖明显更高。已有统计为：

```text
per-case rank3 mean   ≈ 0.9954
per-case rank3 median ≈ 0.9984
```

本次测试集示例 `case105_mises_full_export` 的 by-case PCA/SVD 维度为：

```text
节点曲线数 N = 512
频率点数 F = 77
矩阵形状   = 512 × 77
```

该 case 的解释率为：

```text
rank1 explained = 0.8934
rank2 explained = 0.9754
rank3 explained = 0.9985
```

这说明对于单个 case，前三个 PCA/SVD 分量几乎可以重构圆盘中心节点曲线族。但这三条 by-case basis 是针对该 case 真实 target 曲线直接计算出来的正交主成分，不是模型内部直接输出的曲线。

本次用于对比的模型曲线输出路径为：

```text
node/outputs/compare_model_vs_pca_test_case/
```

其中模型 low-rank curve head 的三条曲线为：

```text
case105_mises_full_export_node11558_peak_curve_values_log_contribution.png
case105_mises_full_export_node11558_peak_curve_values_scaled.png
case105_mises_full_export_node11558_peak_low_rank_curve_values.csv
case105_mises_full_export_node11558_peak_low_rank_decomposition.png
```

对应的 by-case PCA/SVD 曲线为：

```text
cases/case105_mises_full_export_svd_rank3_basis.png
cases/case105_mises_full_export_svd_rank3_curves.csv
cases/case105_mises_full_export_svd_rank3_reconstruction.png
case105_pca_rank3_typical_log_contribution_only.png
case105_pca_rank1_typical_log_contribution.png
case105_pca_rank2_typical_log_contribution.png
case105_pca_rank3_typical_log_contribution.png
```

模型曲线和 PCA/SVD basis 曲线相差较大是正常现象，原因是它们不是同一个数学对象：

- PCA/SVD 的前三条曲线是从真实 target 矩阵中分解出来的正交 basis，强制正交，并按解释能量从大到小排序。
- 模型的 `curve_1/curve_2/curve_3` 是网络内部的 latent curve channels，不要求正交，也不要求按贡献大小排序。
- PCA/SVD 的单条 `basis_k` 或 `S_k / sqrt(N) * basis_k` 不是完整真实曲线；完整重构还需要乘以每条节点自己的 `u_ik` 系数，并加回行均值和频率均值。
- 模型最终预测也不是单独某条 curve，而是 `node_scale + sum_k mixing_weight_k * curve_k + pointwise/residual`。
- 即使模型学到的三维子空间接近 PCA/SVD 子空间，三条曲线本身也可能发生旋转、混合、重排或整体符号翻转，因此不能逐条比较 `PCA rank1` 和 `model curve1`。

因此，正确对比方式不是看单条曲线是否重合，而是看：

```text
PCA/SVD rank3 reconstruction vs 真实 target
模型最终 prediction vs 真实 target
模型 low_rank 部分 vs 真实 target
模型三条 curve 张成的空间 vs PCA/SVD 前三条 basis 张成的空间
```

如果希望把训练数据提取的 PCA/SVD rank3 直接注入模型，作为固定 basis 替代 low-rank curve head，也可以作为一个消融实验：

```text
fixed_basis_k(f) = 训练集全局 PCA/SVD rank3 basis

prediction ≈ node_scale
           + sum_k mixing_weight_k(node) * fixed_basis_k(f)
           + pointwise/residual
```

这个版本更可解释、更稳定，但表达能力会低于当前条件化 curve head。原因是全局固定 rank3 只有约 `87.92%` 覆盖率，而 by-case rank3 通常接近 `99.5%` 以上。当前模型的优势在于 `frequency_head` 可以根据 PSD、模态和 FRF 条件生成随 case 变化的三条曲线，更接近 by-case PCA/SVD 的高覆盖特性。

## 12. 如何正确读图

### 看 `basis` 图

适合观察：

- rank 分量的频率形状。
- 主要峰位在哪里。
- 分量之间是否表达不同频段。
- 分量是否像平滑主趋势、局部峰值、峰位偏移等模式。

不适合观察：

- 原始应力大小。
- 绝对预测值。
- 单个节点真实响应。

### 看 `typical log contribution` 图

适合观察：

- 每个 rank 分量的实际贡献量级。
- 哪个分量主导整体曲线变化。
- 该分量在 log 响应空间中大约能带来多大变化。

不适合直接解释为：

- Mises PSD 原始值。
- 某个真实节点的完整响应。

## 13. 简短结论

这三条全局 rank3 曲线是：

```text
800 个训练 case 的圆盘中心目标曲线
插值到统一频率网格后
做一次全局 SVD 得到的前三个频率方向基函数。
```

其中：

- `Global right singular vector`：只表示单位范数频率形状，无物理单位。
- `S / sqrt(N) * basis`：表示该 rank 分量在 `log1p(target)` 空间中的典型贡献幅度。
- 它们不是完整目标曲线，也不是模型内部固定曲线。
- 它们有随机振动物理来源，但不是独立物理实体，不能直接等同于某阶模态或某条 FRF。
- 完整曲线需要加回均值，并乘上每条曲线自己的 SVD 系数。
- 全局 rank3 解释率为 `0.8792`，明显低于 per-case rank3 的 `~0.995`，说明跨 case 的曲线族变化更复杂。
