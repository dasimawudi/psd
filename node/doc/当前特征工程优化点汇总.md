# 当前特征工程优化点汇总

> 任务：基于 `case + frequency + node` 预测单节点单频点 `MISES_psd_density`  
> 当前主线：耳片区域点级 MLP / 后续可扩展 Hybrid-GNN  
> 更新日期：2026-05-20

---

## 0. 总体判断

当前实验已经证明：

```text
点级 MLP + 物理特征 + 模态特征 + peak/tail 约束
```

是当前最有效的主线方案。后续优化重点不应优先放在“换更复杂模型”，而应放在：

```text
1. 把几何结构换成更适合学习的坐标系
2. 把频率响应换成更接近动力学公式的编码
3. 把模态数据从“振型形状”升级为“模态响应先验”
4. 把高应力热点、峰值和尾部分布显式纳入训练目标
5. 把工程区域、置信度和分桶校准纳入预测闭环
```

一句话概括：

```text
不要让网络从原始 x/y/z/f 中硬学物理，
而是把节点放回“几何区域 + 模态响应 + PSD 激励 + 频率工况 + 峰值约束”的物理上下文中。
```

## 1. 当前已验证有效的基础特征

当前点模型的基础特征体系是合理的，可以作为后续所有版本的 baseline。

### 1.1 节点归一化几何特征

保留：

```text
x_norm
y_norm
z_norm
r_norm
dist_to_edge
sin_theta
cos_theta
```

作用：

- 用相对坐标代替原始绝对坐标；
- 用 `sin_theta / cos_theta` 代替角度，避免角度周期断点；
- 帮助模型识别圆盘结构中的径向、周向和边界位置。

建议：

```text
保留为第一版必选特征。
这类特征已经做了物理归一化，通常不再需要 mean/std 标准化。
```

## 2.1 耳片局部坐标系

### 问题

当前模型主要使用全局圆盘坐标：

```text
x_norm, y_norm, r_norm, sin_theta, cos_theta
```

但热点通常由节点在最近耳片内部的局部位置决定，例如：

```text
靠近耳孔边缘？
靠近耳片根部？
是否位于孔-根部传力路径上？
距离耳片中心线多远？
```

仅用全局坐标会让模型自己去推断这些局部关系，学习难度较大。

### 建议新增特征

对每个节点找到最近耳片，建立局部坐标系：

```text
ear_local_u              # 沿耳片径向方向的位置
ear_local_v              # 垂直耳片径向方向的位置
ear_local_r              # 相对耳片中心的局部半径
ear_local_sin            # 局部角度 sin
ear_local_cos            # 局部角度 cos
dist_to_ear_axis          # 到耳片中心线距离
dist_to_ear_root          # 到耳片根部距离
near_ear_root             # 根部 soft mask
dist_to_hole_center       # 到最近耳孔中心距离
dist_to_hole_edge         # 到耳孔边缘距离
between_hole_and_root_soft # 是否处于孔-根部连接带
```

### 推荐 soft mask

```text
near_ear_root = exp(-max(dist_to_ear_root, 0) / root_band)
near_hole_root_bridge = sigmoid((u - u_hole) / tau) * sigmoid((u_root - u) / tau) * exp(-abs(v) / bridge_width)
```

### 预期改善

```text
耳片根部误差
top1 / top5 MAE
最高峰值桶 peak error
热点形状稳定性
```

### 优先级

```text
S 级：非常建议马上做。
```

## 2.2 多耳片 N-fold 对称性编码

### 问题

如果结构有多个耳片，不同耳片在全局角度上不同，但局部物理结构相似。模型不应该分别记忆每个耳片方向。

### 建议新增

```text
ear_count
nearest_ear_index
theta_relative_to_nearest_ear
sin_theta_relative
cos_theta_relative
abs_theta_relative
sector_phase
sector_center_distance
```

其中：

```text
theta_relative_to_nearest_ear = 当前节点角度 - 最近耳片中心角度
```

### 作用

把多个耳片折叠到统一标准扇区，让模型学习：

```text
“节点在一个标准耳片中的相对位置”
```

而不是学习：

```text
“节点在全局坐标里的具体角度”
```

### 优先级

```text
S 级：和耳片局部坐标系一起做。
```

## 2.3 模态传递函数 / FRF 放大因子

### 问题

当前 `nearest_gap`、`abs_delta_to_top3` 等特征只表达“离模态近不近”，但随机振动响应更接近单自由度频响放大规律。

当前阻尼为全频段统一 2% 临界阻尼，因此可以直接构造 FRF 特征。

### 建议公式

对第 `i` 阶模态：

```text
r_i = f / f_i
zeta = 0.02
modal_amp_i = 1 / sqrt((1 - r_i^2)^2 + (2 * zeta * r_i)^2)
log_modal_amp_i = log1p(modal_amp_i)
```

### 建议新增特征

```text
freq_ratio_i = f / f_i
modal_detuning_i = 1 - freq_ratio_i^2
modal_amp_i_zeta002
log_modal_amp_i_zeta002
modal_weight_i = modal_amp_i / sum_j modal_amp_j
nearest_modal_amp
sum_modal_amp
topk_modal_amp_sum
```

可以同时增加多个阻尼假设：

```text
modal_amp_i_zeta001
modal_amp_i_zeta002
modal_amp_i_zeta005
```

让模型自己学习哪个阻尼尺度更有效。

### 预期改善

```text
near-mode 频率桶
200-500 Hz / 500-1000 Hz 响应峰
case-frequency peak error
最高响应样本低估
```

### 优先级

```text
S 级：非常建议做。
```

---

## 2.4 模态振型每阶内部归一化

### 问题

当前 `U1/U2/U3/U_mag` 是质量归一化振型。质量归一化可以表达模态特征向量，但不同模态、不同 case 的绝对幅值不一定直接可比。

### 建议新增两套模态特征

#### A. 形状归一化特征

每阶模态内部做 max 或 RMS 归一化：

```text
u1_shape_i = U1_i / max(U_mag_i)
u2_shape_i = U2_i / max(U_mag_i)
u3_shape_i = U3_i / max(U_mag_i)
umag_shape_i = U_mag_i / max(U_mag_i)
```

或者：

```text
u1_shape_i = U1_i / rms(U_mag_i)
u2_shape_i = U2_i / rms(U_mag_i)
u3_shape_i = U3_i / rms(U_mag_i)
umag_shape_i = U_mag_i / rms(U_mag_i)
```

#### B. 模态全局尺度摘要

```text
mode_umag_max_i
mode_umag_mean_i
mode_umag_rms_i
axis_energy_u1_i
axis_energy_u2_i
axis_energy_u3_i
```

### 推荐 weighted 特征

```text
weighted_abs_u1_shape = Σ modal_weight_i * abs(u1_shape_i)
weighted_abs_u2_shape = Σ modal_weight_i * abs(u2_shape_i)
weighted_abs_u3_shape = Σ modal_weight_i * abs(u3_shape_i)
weighted_umag_shape   = Σ modal_weight_i * umag_shape_i
```

### 优先级

```text
S 级：建议和 FRF 权重一起做。
```

## 2.5 扩展模态阶数覆盖检查

### 问题

当前只使用前 10 阶模态。是否足够取决于：

```text
前 10 阶是否覆盖 20-2000 Hz 内主要响应峰；
2000 Hz 内实际有多少阶模态；
高响应频段是否存在第 10 阶以后的模态贡献。
```

### 建议检查

对所有 case 统计：

```text
mode_10_frequency 分布
mode_10_frequency > 2000 Hz 的 case 比例
20-2000 Hz 内的模态阶数分布
高误差 case 的 mode_10_frequency 分布
```

### 若前 10 阶不足

建议：

```text
freq_relations 扩展到前 20 阶
mode_shape_count 尝试 20
至少保留前 20 阶 modal_amp_i 和 modal_weight_i
```

### 优先级

```text
A 级：先检查，再决定是否扩展。
```

## 3.1 模态应变 / 模态应力 proxy

### 问题

当前使用的是位移振型，但目标是 `MISES_psd_density`，本质上更接近应力响应，而不是位移响应。

位移大的地方不一定应力最大；固定端、孔边、根部过渡区可能位移不大但应力很高。

### 最佳方案

如果 Abaqus 可以导出每阶模态下的应力或应变场，建议新增：

```text
modal_mises_shape_i
modal_strain_energy_i
nearest_modal_mises_shape
weighted_modal_mises_shape
weighted_modal_strain_shape
```

### 近似方案

如果暂时不能导出 modal stress，可以从位移振型构造局部梯度 proxy：

```text
mode_edge_du_mean
mode_edge_du_max
mode_edge_du_rms
mode_local_strain_proxy = mean_neighbor(|U_i - U_j| / edge_length)
weighted_mode_strain_proxy
nearest_mode_strain_proxy
```

### 预期改善

```text
孔边热点
耳片根部热点
应力集中区域 top1/top5
```

### 优先级

```text
A 级：如果能导出 modal stress/strain，非常值得做。
```

## 4. 训练和目标相关的特征工程 / 表示工程

严格说这部分不完全是“输入特征”，但它直接决定特征是否发挥作用。

## 4.1 PSD 缩放一致性增强

### 物理依据

在线性随机振动中，如果输入 PSD 整体乘以系数 `c`，响应 PSD density 通常也应近似乘以 `c`：

```text
PSD(f) -> c * PSD(f)
MISES_psd_density(f) -> c * MISES_psd_density(f)
```

### 数据增强

```text
PSD' = c * PSD
y' = c * y
```

建议 `c`：

```text
0.5, 0.8, 1.2, 2.0
```

### consistency loss

```text
pred(geometry, c * PSD, f, node) ≈ c * pred(geometry, PSD, f, node)
```

### 预期改善

```text
PSD 幅值泛化
高低激励强度切换
跨 PSD case 泛化
```

### 优先级

```text
S 级：非常值得尝试。
```

---

## 4.2 解析 baseline + residual learning

### 问题

当前模型直接预测：

```text
log(MISES_psd_density)
```

这会让网络从零学习 PSD、模态放大和节点响应形状之间的关系。

### 建议构造粗物理 baseline

例如：

```text
baseline_log =
  log_psd_value_at_frequency
  + log1p(weighted_umag_shape)
  + log1p(nearest_modal_amp)
```

或者：

```text
baseline_raw = psd_value_at_frequency * Σ_i modal_amp_i * umag_shape_i
baseline_log = log1p(baseline_raw)
```

模型预测 residual：

```text
residual = log_y - baseline_log
pred_log_y = baseline_log + mlp_residual
```

### 作用

- 让 PSD 和模态放大由解析 proxy 表达；
- 让 MLP 主要学习局部应力集中修正；
- 有利于高响应样本和跨 case 泛化。

### 优先级

```text
S/A 级：建议作为 v4 重点实验。
```

---

## 4.3 Peak-relative 输出重参数化

### 问题

当前最难的是最高响应桶和峰值低估。逐点预测容易把峰值平均掉。

### 建议结构

先预测 case-frequency 级峰值：

```text
peak_log = peak_head(case, frequency, global/modal features)
```

再预测每个节点相对峰值的下降量：

```text
drop_from_peak = softplus(node_head(node, case, frequency))
node_log_stress = peak_log - drop_from_peak
```

### 优点

- 强制节点预测不超过图级峰值；
- 让模型分别学习“这个频点整体多强”和“节点离峰值差多少”；
- 适合热点主导问题。

### 优先级

```text
A 级：如果 v3 继续存在 peak 低估，应优先尝试。
```

---

## 4.4 高频 / 高响应 bucket curriculum

### 问题

v3 已经证明 sample-level peak/top-tail loss 有效，但最高响应桶仍然是主要短板。

### 建议三阶段训练

```text
Stage 1:
均匀训练，学习整体分布

Stage 2:
增加 top5/top1 点权重，学习热点

Stage 3:
oversample 高响应样本：
- true_peak > p99
- true_mean > p95
- near-mode samples
- 历史误差高的 case-frequency
```

### 优先级

```text
A 级：实现成本低，收益可能明显。
```

---

## 4.5 频率连续性约束

### 问题

当前每个频率点独立预测，但同一 case-node 的响应谱沿频率应相对连续，模态附近出现有规律的峰。

### 建议 loss

对同一 case-node 的相邻频点：

```text
L_freq_shape = mean |(pred_log(f_{i+1}) - pred_log(f_i)) - (true_log(f_{i+1}) - true_log(f_i))|
```

### 作用

- 约束频率方向的谱形状；
- 改善峰附近的响应曲线；
- 减少逐频点预测的抖动。

### 优先级

```text
B+ 级：需要 batch 组织支持，可作为增强实验。
```

---

## 5. 可选结构性增强

---

## 5.1 模态基函数展开

### 核心思想

不要让模型完全从零学习频率曲线，而是把频率响应写成模态基函数叠加：

```text
B_i(f) = modal_amp_i(f)
pred(f, node) = Σ_i a_i(node, case) * B_i(f) * PSD(f)
```

其中模型学习：

```text
a_i(node, case)
```

也就是节点对每阶模态的参与强度。

### 可加 residual

```text
pred_log = log1p(Σ_i a_i * B_i * PSD) + residual_mlp
```

### 优点

- 频率方向由物理基函数控制；
- 峰的位置和宽度更稳定；
- 模型主要学习节点/几何对模态参与系数的影响。

### 优先级

```text
B 级：潜力大，但实现复杂度高于直接 MLP。
```

---

## 5.2 区域专家模型 / Mixture of Experts

### 问题

耳片区域内部仍然包含多个物理子区域：

```text
耳孔边缘
耳片根部
孔-根部连接带
外边界
中心耦合影响区
普通耳片背景
```

一个统一 MLP 可能难以同时拟合这些不同区域。

### 方案一：region embedding

```text
region_id -> embedding
拼接到节点特征
```

### 方案二：Mixture of Experts

```text
shared encoder
+ hole expert
+ root expert
+ bridge expert
+ background expert
+ gating network

pred = Σ gate_i * expert_i_pred
```

### 优先级

```text
B 级：当局部区域误差差异明显时再做。
```

---

## 5.3 MLP + 轻量 GNN residual

### 背景

当前 TransformerConv 弱于 MLP v3，但不能说明图结构无用。更稳的方式是让 GNN 做 residual refinement，而不是从零预测。

### 建议结构

```text
pred0 = MLP_v3(node_features)
residual = LightweightGNN(local_edges, node_features, pred0)
pred = pred0 + residual
```

### 作用

- MLP 负责主预测；
- GNN 只修正局部空间连续性和邻域形状；
- 避免图模型从零学习导致过拟合或整体偏移。

### 优先级

```text
B 级：在 MLP 特征打磨稳定后再做。
```

## 5.4 不确定性 / OOD 特征与输出

### 建议输出

```text
prediction_confidence
geometry_ood_score
frequency_ood_score
modal_gap_confidence
peak_confidence
high_response_risk_score
```

### 简单实现

```text
geometry_ood_score:
当前几何参数距离训练集参数范围的归一化距离

frequency_ood_score:
当前 f/mode_i 比值在训练分布中的稀疏程度

ensemble_uncertainty:
多个 seed 模型预测方差
```

### 工程使用

```text
高置信度：直接使用代理模型
中置信度：使用代理模型 + 安全系数
低置信度：回 Abaqus 复算
```

### 优先级

```text
B 级：模型工程化落地时非常重要。
```

## 6. 后处理校准相关优化

---

## 6.1 分桶校准

### 问题

v3 已经大幅缓解低估，但高响应桶仍可能存在系统偏差。

### 建议

在验证集上按桶统计：

```text
correction = median(target / pred)
```

推理时：

```text
pred_calibrated = pred * correction(bucket)
```

### 建议桶

```text
frequency_bucket:
20-200, 200-500, 500-1000, 1000-2000

mode_bucket:
near_mode, between_modes, far_from_modes

region_bucket:
hole, root, bridge, center, background

response_bucket:
low, mid, high, extreme peak
```

### 优先级

```text
A/B 级：实现简单，可作为工程后处理。
```

---

## 6.2 主动采样 / 数据补充

### 问题

如果继续生成 Abaqus 数据，不应盲目均匀扩充。

### 建议流程

```text
1. 用当前 v3/v4 在 val/test 上找 peak error 最大的 case-frequency
2. 反查这些样本的几何参数、频率桶、模态距离、区域分布
3. 找到高误差集中区域
4. 在这些参数附近增加 DOE 采样
```

### 重点补充区域

```text
高 true_peak 样本
高 target_mean 样本
near-mode 高响应样本
耳片根部 / 孔-根部连接带
前 10 阶模态覆盖不足的高频样本
```

### 优先级

```text
A 级：如果还会继续做仿真数据，建议优先采用。
```

## 7. 不建议加入或需要谨慎的特征

以下特征不建议直接输入，或必须谨慎处理。

| 特征 | 建议 | 原因 |
|---|---|---|
| `case_id` | 不输入 | 容易记忆 case，不利于泛化 |
| `node_id` | 不输入 | 容易记忆节点编号 |
| 原始未归一化 `x/y/z` | 谨慎 | 已有归一化几何特征，重复且尺度不稳 |
| 真实 hotspot label | 不输入 | 标签泄漏 |
| 由真实 `MISES_psd_density` 推出的邻域统计 | 不输入 | 标签泄漏 |
| 当前频率下真实应力邻域均值 | 不输入 | 标签泄漏 |
| 有符号模态振型 | 第一版谨慎 | 模态整体符号可能翻转，建议优先用绝对值或符号不变特征 |
| `nearest_mode_index` | 谨慎 | 离散编号可能引入不连续，优先用 continuous weight/gap/amp |

## 10. 最推荐立刻执行的 5 件事

如果只选下一轮最值得做的 5 个，我建议按这个顺序：



## 11. 最终总结

当前特征工程的核心方向应从：

```text
节点坐标 + 当前频率 + 一些全局参数
```

升级为：

```text
标准化局部几何坐标
+ 多耳片对称性编码
+ 工程区域 soft mask
+ 无量纲几何比例
+ PSD 当前值与频带能量
+ FRF 模态放大因子
+ 归一化模态振型形状
+ 模态应变 / 应力 proxy
+ peak-relative / residual 输出结构
+ 分桶校准与置信度
```

一句话总结：

```text
下一阶段不要把重点放在“更复杂的网络”，
而要把重点放在“更接近物理求解过程的输入表示、目标表示和校准机制”。
```
