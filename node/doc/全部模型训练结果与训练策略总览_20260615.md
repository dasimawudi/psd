# 全部模型训练结果与训练策略总览

日期：2026-06-15  
范围：`node/configs/`、`node/outputs/`、`node/doc/` 中当前可追溯的节点级 `MISES_psd_density` 模型实验。  
说明：本文优先记录已经产出 `metrics.json` 的模型；仅有配置、smoke 或未完成标准 test 的实验单独标注。

## 1. 总体结论

当前最有效的建模路线不是单一全零件模型，而是分区专家模型：

- 耳片：旧主线最佳是 `node_mlp_v5_exp_region_distance_within25_50ep`，高应力区非常稳；最新 `node_mlp_v6_earpiece_low_rank_curves_rank8_fast_eval_yolo` 在标准 per-frequency 指标上整体更强，但还需要补最终 `RMises` 双维度评估。
- 圆盘中心：当前最强是 `node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m`，低秩曲线头和中心区域特征显著提升整体，但 top1/top5 高应力尾部仍是短板。
- 全零件 / fullpart：`node_mlp_v6_fullpart_fusion_low_rank_80g` 在 val fullpart 口径比旧 fullpart 有改善，但仍不能替代耳片和圆盘中心专家模型。
- TransformerConv 当前不如点级 MLP，说明现阶段收益主要来自物理特征工程、区域选择和 loss 设计，而不是简单换图网络结构。

## 2. 统一数据口径

大多数主线实验使用同一份数据：

```text
dataset.root = .cache/mises_psd_next1000_full_export_step0p5_balanced_v1
sample_mode = per_frequency
frequency = 20 Hz ~ 2000 Hz
include_zero_frequency = false
target = log1p(max(MISES_psd_density, 0))
zero_below = p99 * 1e-8
split_seed = 42
```

已完成主线模型的 `resolved_config.yaml` 显示，显式划分通常为：

| split | case 数 |
| --- | ---: |
| train | 800 |
| val | 100 |
| test | 100 |

节点范围按实验线不同：

| 实验线 | `node_scope` / 点集 | 数据选取范围 |
| --- | --- | --- |
| 早期耳片 v1-v5 | `earpiece_region.enabled=true`, `width_scale=1.5` | 耳片区域点，早期未显式写 `node_scope`，实际按耳片区域筛选 |
| v5 region / v6 earpiece | `node_scope: earpiece` 或耳片区域 | 耳片危险区域，宽度系数 1.5 |
| 圆盘中心 | `node_scope: disk_center` | 圆盘中心 / 中心耦合附近；排除边界节点，保留中心节点 |
| fullpart | `node_scope: all_nodes` | 全零件有效节点；通常排除边界节点，保留或按配置处理中心节点 |
| D1/D2/D3 诊断 | `node_scope: all_nodes` + `pointset` | 从全零件中按谱形和区域 mask 选出的三类诊断点 |
| TransformerConv | 耳片区域图 | 使用 mesh `edges.csv` 真实连边，保留耳片有效节点 |

## 3. 特征体系与衍生情况

### 3.1 主特征组

| 特征组 | 代表特征 | 作用 |
| --- | --- | --- |
| 归一化几何 | `x_norm/y_norm/z_norm/r_norm/dist_to_edge/sin_theta/cos_theta` | 让不同尺寸 case 的节点位置可比，表达盘状结构的径向和周向位置 |
| 工程区域距离 | `dist_to_ear_hole`、`near_ear_hole`、`center_couple_signed`、`near_center_couple` | 显式告诉模型节点是否靠近耳孔、耳片根部、中心耦合区和孔边 |
| case 几何参数 | `earpiece_thickness`、`RadialDist`、`TopWidth`、`HoleRadius`、`plate_radius`、`Add_mass` | 支持跨 case 泛化，表达几何和质量变化 |
| PSD 激励 | `psd_*`、`psd_value_at_frequency`、`log_psd_value_at_frequency` | 表达当前频率输入能量 |
| 频率 / 模态 detuning | `frequency`、`log_frequency`、`freq_ratio_mode_*`、`modal_detuning_*` | 表达当前频点与模态频率的距离 |
| 节点振型 proxy | `weighted_umag`、`nearest_umag`、`active*_umag` | 表达当前频率附近该节点在模态形状中的参与强度 |
| modal FRF | `log_modal_gain_frf`、`modal_weight_frf`、`weighted_umag_frf` | 用近似 FRF 放大因子替代纯频率距离 |
| modal gradient | `grad_umag_mean/max`、`grad_vector_mean/max` | 用振型空间梯度近似局部应变 / 应力集中趋势 |
| modal baseline | `modal_baseline_log_*` | 给 MLP 一个物理启发的响应强弱基线 |
| 区域 mask / 距离 | `stress_region_mask`、`center_couple_mask`、`ear_hole_wall_mask` 等 | 注入全零件应力区域先验，区分不同危险区域 |
| 圆盘中心增强 | `center_inner_core_soft`、`center_region_rbf_*`、inner/outer modal aggregation | 细分中心区域环带和局部模态聚合，改善圆盘中心整体拟合 |

## 4. 训练策略演进

### 4.1 早期耳片 MLP：v1 到 v5

| 阶段 | 代表模型 | 数据范围 | 主要策略 |
| --- | --- | --- | --- |
| v1 基线 | `node_mlp_earpiece_case1000_v1` | 耳片区域，per-frequency | MLP `[256,256,128]`，SILU，dropout 0.1，普通 log MAE selection |
| v2 tail | `node_mlp_earpiece_case1000_v2_weighted_tail` | 同 v1 | `target_quantile`，top5 weight 3，top1 weight 8 |
| v3 peak-tail | `node_mlp_earpiece_case1000_v3_peak_tail_composite` | 同 v1 | top5 weight 4、top1 weight 12，加入 sample peak/top1/top5 loss |
| v4 local+FRF | `node_mlp_earpiece_case1000_v4_local_frf_mode_norm_80g` | 同 v1 | 加耳片局部几何、shape norm、modal ratio、modal FRF，batch 1M |
| v5 gradient | `node_mlp_earpiece_case1000_v5_modal_gradient_baseline_80g` | 同 v1 | 加 modal FRF shape、modal gradient、modal baseline，从 v4 初始化 |
| v5 region | `node_mlp_v5_exp_region_distance_within25_50ep` | 耳片区域 + 全零件区域先验 | 加区域距离/mask，selection 更偏 within25 和低误报，训练 50 epoch |

结论：耳片收益最大的特征增量是 `local geometry + modal FRF + modal gradient/baseline + stress region distance`。单纯 tail weighting 收益有限，物理特征和 selection 设计收益更大。

### 4.2 三类点诊断：D1/D2/D3

三类点实验使用同一套 238 维特征，只改变训练点集。

| 实验 | 输出目录 | 点集 | 选点范围 | 目的 |
| --- | --- | --- | --- | --- |
| D1 | `node_mlp_v5_diag_full_flat_background_only_100ep` | `full_flat_background` | 远离应力区域且频谱平坦的背景点 | 判断模型是否会在普通背景区造假峰 |
| D2 | `node_mlp_v5_diag_full_sensitive_flat_only_100ep` | `full_sensitive_flat` | 位于应力区域但真实响应平坦的点 | 判断几何敏感但真实平坦时是否误报 |
| D3 | `node_mlp_v5_diag_full_hotspot_only_100ep` | `full_hotspot` | 任一频点进入 top5% 或高 `max/std/peak_ratio` 的点 | 判断真实热点是否可学 |

诊断结论：

- D1 / D2 的 within25 很低，说明背景和敏感平坦点是当前整体误差的重要来源。
- D3 证明真实热点可学，但单独热点 specialist 不能替代主模型。
- 这些结果支持后续的 hard negative、background false peak、zero gate 等实验。

### 4.3 v6 / v7 耳片背景约束与低秩

| 阶段 | 代表模型 | 数据范围 | 主要策略 |
| --- | --- | --- | --- |
| v6 allpoints | `node_mlp_v6_earpiece_allpoints` | `node_scope: earpiece` | 在 v5 region 基础上加入低目标 bucket、low-target overprediction、background false peak、participation residual |
| v7 ranking | `train7_v7a_ranking_only` | 耳片区域 | 关闭低值压制，加入 pairwise ranking：真 top5 必须高于背景假峰 |
| v8 zero peak | `train7_v8_within25_zero_peak` | 耳片区域 | 加 zero gate、background false peak、peak-relative/drop ranking |
| rank5 low-rank | `node_mlp_v6_earpiece_low_rank_curves_fast_eval_yolo` | 耳片区域 | `curve_rank=5`、`residual_weight=0.15`，从 v6 allpoints 初始化 |
| rank8 low-rank | `node_mlp_v6_earpiece_low_rank_curves_rank8_fast_eval_yolo` | 耳片区域 | `curve_rank=8`、`residual_weight=0.20`，100 epoch，4M batch |

结论：

- v6 背景约束有小幅 overall 收益，但容易压低真实热点。
- v7 ranking 接近旧最佳，但没有超过。
- v8 zero gate 过强，整体明显退化。
- rank8 low-rank 是当前标准 per-frequency 口径下最强耳片模型之一，说明耳片不是不能低秩，而是不能用过低 rank 强压。

### 4.4 圆盘中心

| 阶段 | 代表模型 | 数据范围 | 主要策略 |
| --- | --- | --- | --- |
| baseline | `node_mlp_v6_disk_center_baseline` | `node_scope: disk_center` | 启用 disk center、plate hole、angular periodic、stress region distance、modal FRF/gradient/baseline |
| hotspot features | `node_mlp_v6_disk_center_hotspot_features` | 同 baseline | 增加中心内核/中环/外环 soft band、8 个 RBF、中心区域模态聚合 |
| low-rank | `node_mlp_v6_disk_center_low_rank_curves_fast_eval` | 同 baseline | `low_rank_curve_head=true`、`center_curve_rank=3`、`center_residual_weight=0.10` |
| continue70 | `node_mlp_v6_disk_center_low_rank_curves_fast_eval_continue70_4m` | 同 baseline | 从 low-rank best 继续，70 epoch，batch 4,194,304 |
| calibration/aux | `calibrated_fast_eval`、`hotspot_aux_head`、`peak_calibration` | 同 baseline | 强化 top/peak 或辅助热点头 |

结论：

- 中心区域特征有效，low-rank head 是最大收益来源。
- 圆盘中心曲线强低秩，rank3 已能表达大部分频响。
- 简单峰值校准和 hotspot aux 会造成全局过预测，不能解决 top1/top5 排序不足。

### 4.5 fullpart / fusion

| 阶段 | 代表模型 | 数据范围 | 主要策略 |
| --- | --- | --- | --- |
| fullpart baseline | `node_mlp_v6_fullpart_disk_center` | `node_scope: all_nodes` | 全零件点，融合耳片和圆盘中心特征，从 v6 earpiece 初始化 |
| fusion low-rank | `node_mlp_v6_fullpart_fusion_low_rank_80g` | 全零件 | 加 disk center RBF/modal region、rank8 low-rank、从圆盘中心 best 初始化并混入耳片 checkpoint |
| ear-region loss | `node_mlp_v6_fullpart_fusion_ear_region_loss_80g` | 全零件 | 在 fusion 基础上增加耳片区域点权重、top1/top5 under loss |

结论：fusion 方向有一定 val 改善，但当前仍不能替代分区专家模型；圆盘中心高值和耳片高值同时兼顾仍困难。
