### 损失函数

在 `log1p` 空间计算 MSE 为基础，叠加多层加权策略：

| 损失组件 | 配置 | 作用 |
|---|---|---|
| 逐点分位加权 | `weighting: target_quantile` | 按目标值在全样本中的分位自适应加权 |
| 高响应点加权 | `top1_weight=12.0`, `top5_weight=4.0` | 强化对峰值点的拟合 |
| 目标值分桶加权 | `[0,1)×1.35`, `[1,10)×1.2`, `[10,100)×1.1` | 低目标值区域适度提权 |
| 低目标过预测惩罚 | `weight=0.05`, target∈[0,100] | 抑制对低应力区域的高估 |
| 样本级峰值 loss | `peak=0.22`, `top5=0.18`, `top1=0.3` | 每帧内 top1%/top5%/峰值点额外监督 |
| 背景误峰抑制 | `weight=0.006`, margin=log(1.5) | 防止将低应力误判为峰值 |
| 中心区域点加权 | `center_region_point_weight=1.6` | 圆盘中心区域逐点加权 |
| disk_center 峰值 loss | `top5=0.18`, `top1=0.32` | disk_center 子区域独立 top 峰值监督 |

## 评估口径

`top1% / top2% / top5% / top10% / top15% / top25%` 按百分比占比定义。

具体定义：对每个 case-frequency 帧，在全部节点（或区域内部节点）内，按真实 `MISES_psd_density` 从大到小排序，取 `rank / node_count <= 1% / 2% / 5% / 10% / 15% / 25%` 的累计高响应点，再汇总所有帧计算指标。

主要指标：
- `within25`：相对误差 `abs(pred - target) / abs(target) <= 25%` 的点占比。
- `相对 MAE`：逐点相对误差均值 `mean(abs(pred - target) / target)`（仅正目标）。
- `相对 log MAE`：`log1p(MISES_psd_density)` 空间里的 MAE，即 `mean(abs(log1p(pred) - log1p(target)))`。

## 数据集规模

数据按 case 维度 `train_ratio=0.8` 拆分，约 1000 个 case，随机划分为 train/val/test。每帧为非空的 case-frequency 样本。本模型保留全部节点（含 inner disk 区域）。

| 划分 | 样本数 | 总点数 | 耳片区域点数 | 圆盘区域点数 |
|---:|---:|---:|---:|---:|
| 训练集 | 82,538 | 1,997,514,226 | ~2.4 亿 (估) | ~17.6 亿 (估) |

| 测试集 | 10,607 | 256,133,337 | 31,666,289 | 224,467,048 |

> 注：训练集不按区域单独统计，耳片/圆盘点数为按 val 区域占比（耳片 11.92%、圆盘 88.08%）估算。圆盘区域包含 disk_center 子区域（val 集 37,660,224 点），本模型未排除 inner disk 节点，因此 val/test 集总点数和圆盘点数均显著大于 remove_inner_disk 模型。

## 总结

1. **圆盘区域是 continue32 基线的优势区域**：overall within25 = 55.93%，相对 log MAE = 0.2541，是三个区域中整体表现最好的。但 top1% 的 within25 仅 43.92%（甚至低于 top25% 的 51.74%），说明圆盘区域峰值点拟合是核心短板。

2. **耳片区域高响应点拟合尚可但整体仍有差距**：overall within25 仅 36.41%，但 top5% within25 达 58.19%（全模型的最高值）。耳片区域内中低响应点误差极大（相对 MAE 173.86%）严重拉低了区域整体指标。

3. **全零件 top1% within25 = 56.24%**，top5% = 50.11%，该水平为 remove_inner_disk 模型的改进基线。

4. **与 remove_inner_disk 模型的对比**：remove_inner_disk 以本模型 best.pt 为初始化权重，排除 inner disk 节点后继续训练 100 epoch，在全部维度均有提升（详见 remove_inner_disk 报告）。
