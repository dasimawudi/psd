# 振型数据增强利用方案：从普通特征到模态响应基函数

> 适用任务：基于点的 `MISES_psd_density` 预测  
> 当前建模形式：`case + frequency + node -> MISES_psd_density`  
> 核心目标：把 `mode_shapes` 从普通节点特征升级为频域响应的模态基函数、应变/应力 proxy 和物理 baseline。

---

## 1. 核心判断

当前不是“没有用振型”，而是**只用了振型数据的第一层价值**。

当前常见做法是：

```text
当前频率 f
→ 根据 f 与各阶模态频率的距离计算权重
→ 对 U1/U2/U3/U_mag 做 weighted / nearest 摘要
→ 拼到节点特征
→ MLP 或 GNN 预测 MISES_psd_density
```

这个做法是正确的第一步，因为它把“当前频点可能激发出什么空间形态”作为节点侧先验输入。

但它仍然停留在：

```text
振型 = 额外节点特征
```

更推荐升级为：

```text
振型 = 模态响应基函数 + 应变/应力 proxy + 物理 baseline + residual learning
```

也就是说，不要再让网络自己从 `U_mag` 里猜应力，而是先用模态物理把以下信息显式算出来：

```text
1. 哪些模态在当前频率下被放大？
2. 这些模态在空间上哪里活跃？
3. 哪些节点附近存在振型梯度/应变集中？
4. PSD 输入能量经过模态响应后大致形成什么 baseline？
5. 神经网络只学习 baseline 解释不了的局部修正。
```

---

## 2. 当前模态数据的物理含义

当前 `mode_shapes/*.csv` 中通常包含：

| 字段 | 含义 |
|---|---|
| `node_index` | 导出后的节点顺序编号 |
| `node_label` | Abaqus 原始节点号 |
| `x, y, z` | 节点坐标 |
| `bc_mask` | 是否属于固定边界节点 |
| `U1, U2, U3` | 该模态下节点在 X/Y/Z 三个方向的振型位移分量 |
| `U_mag` | `sqrt(U1^2 + U2^2 + U3^2)` |

需要强调：

```text
U1/U2/U3/U_mag 不是受载后的真实位移，
而是模态振型向量，即特征向量。
```

当前 FrequencyStep 使用质量归一化：

```text
φ_i^T M φ_i = 1
```

因此：

```text
可以用它看相对形状、相对活跃区域、方向分布；
不能把它直接解释成真实 mm 位移幅值。
```

当前随机响应计算使用全频段统一 2% 临界阻尼：

```text
ζ = 0.02
```

这个信息非常关键，因为它允许我们直接构造频响放大因子，而不是只用经验 gap 权重。

---

## 3. 总体技术路线

建议构建一个新的版本：

```text
Modal-Response Enhanced Point Model
```

输入仍然是：

```text
case + frequency + node -> MISES_psd_density
```

但模态部分从原来的：

```text
weighted U / nearest U
```

升级为：

```text
1. mode shape 形状归一化
2. 2% 阻尼 FRF 模态放大因子
3. active top-k 模态特征
4. 模态振型梯度 / 应变 proxy
5. 模态参与因子
6. case-frequency 全局模态摘要
7. modal baseline + residual prediction
```

整体数据流：

```text
节点几何特征
+ 工程区域距离特征
+ PSD 特征
+ 频率-模态关系特征
+ FRF 模态响应特征
+ 模态位移形状特征
+ 模态梯度/应变 proxy
+ modal baseline
→ MLP 预测 residual
→ pred_log = baseline_log + residual
→ MISES_psd_density_pred = expm1(pred_log)
```

## 4. 阶段一：模态覆盖检查

### 4.1 为什么要检查

当前数据使用前 10 阶模态，但预测频率范围是：

```text
20 Hz - 2000 Hz
```

前 10 阶是否足够，取决于：

```text
1. 第 10 阶模态频率是否覆盖到 2000 Hz；
2. 20-2000 Hz 内到底有多少阶模态；
3. 高响应峰附近是否有被导出的模态；
4. Abaqus 随机响应实际参与的模态数量是否超过当前导出数量。
```

### 4.2 检查脚本

建议新增脚本：

```text
scripts/check_modal_coverage.py
```

输出：

```text
每个 case 的：
- mode_1_frequency
- mode_3_frequency
- mode_10_frequency
- 20-2000Hz 内模态数量
- mode_10_frequency 是否 > 2000Hz
- 高响应频点附近最近模态距离
```

### 4.3 判断规则

```text
如果多数 case 的 mode_10_frequency > 2000Hz：
    前 10 阶基本够用，可以先不扩展。

如果大量 case 的 mode_10_frequency < 2000Hz：
    前 10 阶不够，建议扩展到前 20 阶。

如果高响应峰出现在未覆盖模态附近：
    必须增加模态数量，否则模型缺少关键物理先验。
```

## 5. 阶段二：模态振型归一化

### 5.1 问题

质量归一化振型的绝对幅值不应直接跨模态、跨 case 比较。当前如果直接使用原始 `U1/U2/U3/U_mag`，模型可能学到质量归一化尺度带来的噪声。

### 5.2 每阶内部 max 归一化

对第 `i` 阶模态：

```text
umag_i(node) = sqrt(U1_i^2 + U2_i^2 + U3_i^2)
scale_i = max_node(umag_i(node)) + eps

u1_shape_i = U1_i / scale_i
u2_shape_i = U2_i / scale_i
u3_shape_i = U3_i / scale_i
umag_shape_i = umag_i / scale_i
```

优点：

```text
每阶模态的最大空间幅值统一到 1，
更适合表达“该节点在该模态中的相对活跃程度”。
```

### 5.3 RMS 归一化备选

```text
scale_i = rms_node(umag_i(node)) + eps

u1_shape_i = U1_i / scale_i
u2_shape_i = U2_i / scale_i
u3_shape_i = U3_i / scale_i
umag_shape_i = umag_i / scale_i
```

优点：

```text
对局部极值不那么敏感。
```

第一轮建议：

```text
先用 max_umag 归一化，后续再做 max vs rms 消融。
```

### 5.4 符号处理

模态整体符号可能翻转，所以第一版主特征建议使用：

```text
abs(u1_shape_i)
abs(u2_shape_i)
abs(u3_shape_i)
umag_shape_i
```

不建议第一版直接使用：

```text
signed_u1_shape_i
signed_u2_shape_i
signed_u3_shape_i
```

如果后续要使用有符号特征，需要先做符号对齐，例如：

```text
让每阶模态在某个参考区域的主方向平均值为正。
```

## 6. 阶段三：2% 阻尼 FRF 模态放大因子

### 6.1 从经验 gap 权重升级为 FRF 权重

当前已有 `resonance / log_gaussian / inverse_log_gap` 等经验权重。下一版建议使用 2% 阻尼下的单自由度频响近似。

对第 `i` 阶模态：

```text
r_i = f / f_i
ζ = 0.02
```

响应幅值增益：

```text
H_amp_i(f) = 1 / sqrt((1 - r_i^2)^2 + (2ζr_i)^2)
```

由于目标是 PSD density，更相关的是传递函数幅值平方：

```text
H_psd_i(f) = H_amp_i(f)^2
```

建议保留特征：

```text
freq_ratio_i = f / f_i
modal_amp_i = H_amp_i(f)
modal_psd_gain_i = H_psd_i(f)
log_modal_amp_i = log1p(modal_amp_i)
log_modal_psd_gain_i = log1p(modal_psd_gain_i)
```

### 6.2 clipping

为避免共振点附近数值过大：

```text
modal_amp_i = clip(modal_amp_i, 0, amp_clip)
modal_psd_gain_i = clip(modal_psd_gain_i, 0, psd_gain_clip)
```

推荐初值：

```text
amp_clip = 100
psd_gain_clip = 10000
```

### 6.3 模态权重

使用 PSD gain 构造权重：

```text
w_i(f) = modal_psd_gain_i(f) / sum_j modal_psd_gain_j(f)
```

如果考虑输入 PSD：

```text
modal_energy_i = modal_psd_gain_i(f) * psd_value_at_frequency
w_i(f) = modal_energy_i / sum_j modal_energy_j
```

由于同一频率点的 `psd_value_at_frequency` 对所有模态相同，所以是否乘 PSD 不影响归一化权重，但 `modal_energy_i` 本身仍然是有价值的幅值特征。

## 7. 阶段四：节点级模态特征重构

### 7.1 FRF-weighted 模态形状特征

基于 FRF 权重：

```text
weighted_abs_u1_frf = Σ_i w_i * abs(u1_shape_i)
weighted_abs_u2_frf = Σ_i w_i * abs(u2_shape_i)
weighted_abs_u3_frf = Σ_i w_i * abs(u3_shape_i)
weighted_umag_frf   = Σ_i w_i * umag_shape_i
```

这些特征用于替代或补充当前经验权重下的：

```text
weighted_abs_u1/u2/u3/umag
```

### 7.2 最近模态特征

保留最近模态，但补充 FRF 信息：

```text
nearest_mode_freq
nearest_gap
nearest_abs_u1_norm
nearest_abs_u2_norm
nearest_abs_u3_norm
nearest_umag_norm
nearest_modal_amp
nearest_modal_psd_gain
```

注意：

```text
nearest_mode_index 不建议直接作为整数输入。
```

如果需要表达模态编号，建议使用 one-hot 或 active top-k 模态表示。

### 7.3 Active top-k 模态特征

只做 weighted sum 会丢失“单模态主导”和“多模态叠加”的差别。建议保留当前频率下贡献最大的前 K 个模态。

推荐：

```text
K = 3
```

排序依据：

```text
modal_psd_gain_i
```

每个 active mode 保留：

```text
active1_mode_freq
active1_freq_ratio
active1_modal_amp
active1_modal_psd_gain
active1_abs_u1
active1_abs_u2
active1_abs_u3
active1_umag

active2_...
active3_...
```

这样模型可以区分：

```text
1. 单一强模态主导；
2. 两个相邻模态共同作用；
3. 多个弱模态叠加。
```

## 8. 阶段五：从位移振型构造应变 / 应力 proxy

### 8.1 为什么需要应变 proxy

当前目标是：

```text
MISES_psd_density
```

它是应力 PSD，不是位移 PSD。位移大的地方不一定应力大；应力热点通常出现在：

```text
孔边
耳片根部
孔-根部连接带
约束附近
几何突变处
局部曲率变化处
```

因此，仅使用 `weighted_umag` 不够，需要构造接近应变或应力的 proxy。

### 8.2 简单版：边差分梯度

基于 `edges.csv` 的邻接关系，对第 `i` 阶模态、节点 `p` 及其邻居 `q`：

```text
du1_edge = |u1_shape_i(p) - u1_shape_i(q)| / (edge_dist + eps)
du2_edge = |u2_shape_i(p) - u2_shape_i(q)| / (edge_dist + eps)
du3_edge = |u3_shape_i(p) - u3_shape_i(q)| / (edge_dist + eps)
dumag_edge = |umag_shape_i(p) - umag_shape_i(q)| / (edge_dist + eps)
```

聚合到节点：

```text
mode_grad_u1_mean_i(p)
mode_grad_u2_mean_i(p)
mode_grad_u3_mean_i(p)
mode_grad_umag_mean_i(p)
mode_grad_umag_max_i(p)
mode_grad_umag_rms_i(p)
```

第一版建议至少保留：

```text
mode_grad_umag_mean_i
mode_grad_umag_max_i
```

### 8.3 FRF-weighted 梯度特征

```text
weighted_grad_umag_mean = Σ_i w_i * mode_grad_umag_mean_i
weighted_grad_umag_max  = Σ_i w_i * mode_grad_umag_max_i
```

最近模态：

```text
nearest_grad_umag_mean
nearest_grad_umag_max
```

Active top-k：

```text
active1_grad_umag_mean
active1_grad_umag_max
active2_grad_...
active3_grad_...
```

### 8.4 强化版：局部最小二乘梯度

如果希望更物理，可以对每个节点用邻域点拟合：

```text
U(x, y, z) ≈ a0 + ax*x + ay*y + az*z
```

得到：

```text
∂U1/∂x, ∂U1/∂y, ∂U1/∂z
∂U2/∂x, ∂U2/∂y, ∂U2/∂z
∂U3/∂x, ∂U3/∂y, ∂U3/∂z
```

近似小应变：

```text
εxx ≈ ∂U1/∂x
εyy ≈ ∂U2/∂y
εzz ≈ ∂U3/∂z
γxy ≈ ∂U1/∂y + ∂U2/∂x
γxz ≈ ∂U1/∂z + ∂U3/∂x
γyz ≈ ∂U2/∂z + ∂U3/∂y
```

构造 von Mises strain proxy：

```text
strain_vm_proxy = sqrt(
  0.5*((εxx-εyy)^2 + (εyy-εzz)^2 + (εzz-εxx)^2)
  + 3/4*(γxy^2 + γxz^2 + γyz^2)
)
```

然后：

```text
weighted_strain_vm_proxy = Σ_i w_i * strain_vm_proxy_i
nearest_strain_vm_proxy
active_topk_strain_vm_proxy
```

建议先做边差分版本，再做最小二乘版本。

```text
mode_stress_shapes/mode_001_mises.csv
mode_strain_shapes/mode_001.csv
```

```text
node_label
S11, S22, S33, S12, S13, S23
MISES_modal

```

构造：

```text
modal_mises_shape_i = MISES_modal_i / max(MISES_modal_i)

nearest_modal_mises_shape
```

优先级判断：

```text
如果 modal stress 能稳定导出：
```

## 10. 阶段七：模态参与因子

频率接近某阶模态，不代表该模态一定被强烈激发。还要看激励方向与该模态是否耦合。

理论参与因子：

```text
Γ_i = φ_i^T M r
```

其中：

```text
φ_i = 第 i 阶模态
M = 质量矩阵
r = 激励方向向量
```

如果暂时没有质量矩阵，可以先用近似：

```text
participation_x_i = mean_node(u1_shape_i)
participation_y_i = mean_node(u2_shape_i)
participation_z_i = mean_node(u3_shape_i)
```

如果随机激励主要在 Z 方向，则重点使用：

```text
participation_z_i
```

有效模态贡献：

```text
effective_modal_gain_i = modal_psd_gain_i * abs(participation_dir_i)
```

权重：

```text
w_i = effective_modal_gain_i / sum_j effective_modal_gain_j
```

这样模型可以知道：

```text
某阶模态虽然频率很近，
但如果和激励方向耦合弱，实际贡献可能并不大。
```

## 11. 阶段八：case-frequency 全局模态摘要

除了节点级模态特征，还需要 case-frequency 级别的全局模态状态。

### 11.1 频响强度类

```text
modal_psd_gain_max
modal_psd_gain_sum
modal_psd_gain_mean
modal_psd_gain_entropy
nearest_modal_psd_gain
top1_modal_psd_gain
top2_modal_psd_gain
top3_modal_psd_gain
```

模态增益熵：

```text
p_i = modal_psd_gain_i / sum_j modal_psd_gain_j
entropy = -Σ p_i log(p_i + eps)
```

用于区分：

```text
单模态主导 vs 多模态共同作用
```

### 11.2 空间集中度类

```text
weighted_umag_global_mean
weighted_umag_global_max
weighted_umag_global_std
weighted_grad_global_mean
weighted_grad_global_max
weighted_grad_global_std
```

作用：

```text
告诉模型当前 case-frequency 的模态响应是全局分散，还是局部高度集中。
```

### 11.3 方向能量类

每阶模态：

```text
axis_energy_u1_i = mean(U1_i^2) / mean(U1_i^2 + U2_i^2 + U3_i^2)
axis_energy_u2_i = mean(U2_i^2) / mean(U1_i^2 + U2_i^2 + U3_i^2)
axis_energy_u3_i = mean(U3_i^2) / mean(U1_i^2 + U2_i^2 + U3_i^2)
```

加权汇总：

```text
weighted_axis_energy_u1 = Σ_i w_i * axis_energy_u1_i
weighted_axis_energy_u2 = Σ_i w_i * axis_energy_u2_i
weighted_axis_energy_u3 = Σ_i w_i * axis_energy_u3_i
```

## 12. 阶段九：modal baseline + residual learning

这是整个方案最重要的结构改造。

### 12.1 不再直接预测绝对应力

原始目标：

```text
target_log = log1p(MISES_psd_density)
```

不要让模型直接从零预测 `target_log`。

改成：

```text
pred_log = baseline_log + residual_pred
```

其中：

```text
baseline_log = 由模态物理近似得到
residual_pred = MLP 学习的局部修正
```

### 12.2 Baseline 版本 A：位移振型版

```text
baseline_raw(node, f)
= psd(f) * Σ_i [modal_psd_gain_i(f) * umag_shape_i(node)]

baseline_log = log1p(baseline_raw)
```

优点：实现简单。  
缺点：对应力热点不够直接。

### 12.3 Baseline 版本 B：梯度 / 应变 proxy 版

```text
baseline_raw(node, f)
= psd(f) * Σ_i [modal_psd_gain_i(f) * mode_grad_umag_i(node)]
```

或：

```text
baseline_raw(node, f)
= psd(f) * Σ_i [modal_psd_gain_i(f) * strain_vm_proxy_i(node)]
```

这是推荐优先版本。

### 12.4 Baseline 版本 C：modal stress shape 版

如果能导出模态应力：

```text
baseline_raw(node, f)
= psd(f) * Σ_i [modal_psd_gain_i(f) * modal_mises_shape_i(node)]
```

这是最理想版本。

### 12.5 Residual 训练

```text
target_log = log1p(MISES_psd_density)
residual_target = target_log - baseline_log
```

模型输出：

```text
residual_pred = MLP(features)
pred_log = baseline_log + residual_pred
```

训练 loss 建议直接对最终预测：

```text
L_point = SmoothL1(pred_log, target_log)
```

不建议第一版只对 residual 做 loss，因为 baseline 可能存在整体尺度偏差。

## 13. 频率连续性约束

在 modal baseline 之后，可以加入频率方向的 shape consistency。

对同一个 `case-node` 的相邻频点：

```text
Δpred = pred_log(f_{k+1}) - pred_log(f_k)
Δtrue = true_log(f_{k+1}) - true_log(f_k)
```

损失：

```text
L_freq_shape = mean |Δpred - Δtrue|
```

总 loss：

```text
L_total =
  L_point
  + λ_peak * L_peak
  + λ_topk * L_topk
  + λ_freq * L_freq_shape
  + λ_residual_reg * L_residual_reg
```

建议初始：

```text
λ_freq = 0.02 ~ 0.05
```

注意：

```text
不要直接惩罚 pred(f+1)-pred(f) 变小，
否则会压平真实共振峰。
```

正确约束是：

```text
预测谱线的变化量接近真实谱线的变化量。
```

## 14. 模型结构建议

### 14.1 最小改造：Residual MLP

```text
input_features
→ MLP
→ residual_pred

pred_log = modal_baseline_log + residual_pred
```

### 14.2 推荐结构：三分支 MLP

```text
geom_encoder:
  geometry + region + neighbor features -> h_geom

modal_encoder:
  modal shape + FRF + gradient + baseline features -> h_modal

global_encoder:
  case geometry + PSD + modal global summary -> h_global

fusion:
  [h_geom, h_modal, h_global] -> residual_pred
```

优点：

```text
避免把模态物理特征和普通几何特征完全混在一起；
便于后续做 feature ablation；
便于诊断到底是几何分支还是模态分支在起作用。
```

## 15. Loss 设计

### 15.1 点级 loss

```text
L_point = SmoothL1(pred_log, target_log)
```

### 15.2 Peak loss

对每个 case-frequency：

```text
pred_peak = max_node(pred_log)
true_peak = max_node(target_log)
L_peak = SmoothL1(pred_peak, true_peak)
```

### 15.3 Top-k loss

```text
L_top1 = SmoothL1(pred_log on true top1% nodes, target_log)
L_top5 = SmoothL1(pred_log on true top5% nodes, target_log)
```

### 15.4 频率形状 loss

```text
L_freq_shape =
mean |(pred_log_f2 - pred_log_f1) - (true_log_f2 - true_log_f1)|
```

只在同一 `case-node` 的相邻频点上计算。

### 15.5 Residual 正则

```text
L_residual_reg = mean(residual_pred^2)
```

作用：

```text
防止 residual 完全推翻 modal baseline。
```

推荐初始权重：

```text
λ_peak = 0.2
λ_topk = 0.2
λ_freq = 0.03
λ_residual_reg = 1e-4
```

## 21. 预期收益

## 22. 最终总结

当前振型数据不是没用，而是只用了约 30%。

已经使用的是：

```text
振型作为节点空间先验；
当前频率附近的 weighted / nearest 模态摘要。
```

尚未充分使用的是：

```text
2% 阻尼下的真实 FRF 放大结构；
PSD 响应应使用 |H|^2 的事实；
位移振型到应变/应力热点的转换；
模态参与因子；
模态叠加 baseline；
residual learning。
```

下一步主线建议：

```text
归一化 mode shape
+ FRF modal gain
+ modal gradient / strain proxy
+ modal baseline
+ residual MLP
```

一句话概括：

```text
不要让网络自己从 U_mag 里猜应力；
先用模态物理把“哪里会响应、响应会被放大多少、哪里可能有应变集中”算出来，
再让网络学习剩下的局部修正。
```
