# Node 模型训练结果汇总

更新日期：2026-06-03（Asia/Shanghai）
当前整理分支：`feature/node-mlp-disk-center-ablation`
任务：基于 per-frequency 节点特征预测 `MISES_psd_density`，重点关注耳片、圆盘中心和全区域/全圆盘三类场景。

## 1. 当前结论

- 当前综合最好模型仍是 `node_mlp_v5_exp_region_distance_within25_50ep`。
- 它在耳片主任务上是当前最佳：val log MAE `0.2830`，test log MAE `0.2831`，test miss25 `0.4095`。
- 如果只看耳片 `miss25_rate`，`node_mlp_v6_earpiece_allpoints` 略低：val miss25 `0.4049`；但综合 log、top1、top5 和 test miss25 仍不如当前最佳。
- 圆盘中心当前最佳是 `node_mlp_v6_disk_center_baseline`。它是专门的 `disk_center` 模型，test log MAE `0.2807`，test miss25 `0.4114`。
- 全区域/全圆盘当前最佳是 `node_mlp_v6_fullpart_disk_center`。它是目前唯一有完整 fullpart / earpiece / disk / disk_center 分区评估的 best 模型。

## 7. 当前主要缺口

- 耳片主任务已经把整体 log MAE 压到约 `0.283`，但 miss25 仍在 `0.405` 左右，还有提升空间。
- 圆盘中心 baseline 的整体 log/miss25 已经不错，但 top1/top5 峰值误差仍大。
- fullpart 模型已经能稳定跑完 30 epoch，但圆盘区域，尤其圆盘中心高值区，仍有明显系统性低估。
