# Node 模型训练结果汇总

更新日期：2026-06-03（Asia/Shanghai）
当前整理分支：`feature/node-mlp-disk-center-ablation`
任务：基于 per-frequency 节点特征预测 `MISES_psd_density`，当前重点关注耳片、圆盘中心和全区域/全圆盘三类场景。

## 1. 当前结论

- 当前综合最好模型仍是 `node_mlp_v5_exp_region_distance_within25_50ep`，也是耳片主任务当前首选。
- 如果只看耳片 `miss25_rate`，`node_mlp_v6_earpiece_allpoints` 略低，但综合 log、top1、top5 和 test 指标仍略输。
- 圆盘中心当前最好是 `node_mlp_v6_disk_center_baseline`，它是专门的 `disk_center` 模型，不能与耳片-only 或 fullpart 模型按任务难度直接横比。
- 全区域/全圆盘当前最好是 `node_mlp_v6_fullpart_disk_center`；它也是当前唯一带完整 `fullpart / earpiece_region / disk / disk_center` 分区 top-k 评估的 best 模型。

## 10. 当前主要缺口

- 耳片主任务已经把整体 log MAE 压到约 `0.283`，但 `miss25_rate` 仍在 `0.405` 左右，还有提升空间。
- 当前最佳耳片模型在 top1 峰值点仍有低估，尽管 top5/top10 已经比较稳。
- 圆盘中心 baseline 的整体 log/miss25 已经不错，但 top1/top5 峰值误差仍大。
- fullpart 模型已经能稳定跑完 30 epoch，但圆盘区域，尤其圆盘中心高值区，仍有明显系统性低估。
